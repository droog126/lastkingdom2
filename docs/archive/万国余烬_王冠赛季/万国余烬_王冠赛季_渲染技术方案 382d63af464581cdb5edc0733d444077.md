# 万国余烬：王冠赛季 渲染技术方案

**版本**：V2.0 重构设计版

**适用范围**：Bevy 0.18 客户端渲染、材质、光照、VFX、可读性、性能预算

**最后更新**：2026-06-17

**文档定位**：本文件是渲染实现事实源。美术颜色以《美术风格与色彩规范》为准，玩法状态以《蓝皮书》和《Bevy 0.18 架构实现》为准。

---

## 1. 渲染目标

渲染要服务三个目标：

1. **魔幻优雅**：剑术要轻盈、有轨迹和节奏；法术要有符文、法阵、灵脉和仪式感。
2. **PVP 可读**：敌我、保护期、火种、神器、危险区、阵眼进度必须比环境装饰优先。
3. **性能稳定**：60 人混战时主动降级低优先级特效，不让粒子和透明材质毁掉帧率。

画面基调：低饱和地形和建筑，资源与王权目标局部高亮。普通世界可信，关键目标发光。

## 2. Bevy 渲染插件拆分

客户端新增渲染专项插件，不放进 `ember_game` 权威模拟。

```rust
pub struct EmberRenderPlugin;

impl Plugin for EmberRenderPlugin {
    fn build(&self, app: &mut App) {
        app.add_plugins((
            RenderAssetPlugin,
            WorldMaterialPlugin,
            CharacterRenderPlugin,
            VfxPlugin,
            OutlinePlugin,
            MinimapRenderPlugin,
            ProceduralArtPlugin,
            RenderBudgetPlugin,
        ));
    }
}
```

| 插件 | 职责 |
| --- | --- |
| `RenderAssetPlugin` | glTF、纹理、材质、shader 资源加载和热更新 |
| `WorldMaterialPlugin` | 地形、建筑、资源、灵脉、灾变材质 |
| `CharacterRenderPlugin` | 角色外观、装备挂点、动画可视状态 |
| `VfxPlugin` | 剑轨、法术、采集、受击、神器、法阵 |
| `OutlinePlugin` | 敌我描边、可交互物描边、高价值目标轮廓 |
| `MinimapRenderPlugin` | 小地图标记、区域、脉冲目标 |
| `ProceduralArtPlugin` | 地形材质、资源节点、矿坑模块、POI、地形覆盖层、剑轨法阵和地图图层的程序化生成 |
| `RenderBudgetPlugin` | LOD、特效池、远距隐藏、低配降级 |

## 4.1 30Hz 模拟到高帧渲染

渲染层永远不直接使用权威实体的裸 `Transform` 做最终画面位置。每个可见角色、怪物、大件、火种和神器都应有一个可视代理实体。

```
Authority Entity
  SimTransform(previous/current/tick)
  Gameplay Components
  RenderProxy(visual_entity)

Visual Entity
  Transform(interpolated)
  Mesh / Material / Animation
  VFX Anchors
```

渲染更新：

- `FixedUpdate` 更新 `SimTransform.previous/current`。
- `Update` 计算插值 alpha，并写入 visual entity 的 `Transform`。
- 动画状态按权威状态切换，但混合权重按渲染 `delta` 推进。
- 剑轨、披风、粒子和相机震动只跟随 visual entity。

本地玩家可以预测移动，但渲染层必须保留“服务端纠偏入口”。一旦权威位置和预测位置偏差过大，优先修正角色位移，再用动画、脚步和短暂失衡效果遮住突兀感。

远端玩家不预测细节动作，只插值快照。攻击和施法通过权威事件触发动画，位置使用快照缓冲平滑。

## 5. 材质策略

### 5.1 普通世界材质

普通世界用标准 PBR 思路：

- 草地、泥地、岩地：低金属度，粗糙度偏高。
- 木材：年轮、切面、劈裂边，不发光。
- 石料：冷灰、边缘磨损，不用符文紫。
- 道路：比泥地更浅、更干，便于玩家判断疾跑路线。

### 5.2 魔法材质

魔法材质使用自定义参数，但必须可降级：

| 材质 | 参数 | 视觉 |
| --- | --- | --- |
| `SpiritFlowMaterial` | flow_speed, pulse, tint, noise_scale | 灵脉流动、灵质采集脉冲 |
| `RuneLineMaterial` | line_width, glow, activation | 符文槽、遗迹机关、法阵边线 |
| `ArtifactCoreMaterial` | crown_pulse, secondary_color, reveal_phase | 神器黑金外圈和专属副色 |
| `ShieldVeilMaterial` | opacity, ripple, faction_color | 结界透明波纹 |
| `DangerFieldMaterial` | edge_intensity, stripe_speed | 禁区、污染区、灰烬风暴边界 |

### 5.3 低配降级

| 高配 | 低配 |
| --- | --- |
| 动态流动 shader | 静态贴图 + 简单脉冲 |
| 多层透明法阵 | 单层 mesh 圆环 |
| 长剑轨 ribbon | 短尾迹或闪光弧 |
| 粒子粉尘 | 少量 billboard |
| 实时阴影多光源 | 主光阴影 + 无阴影补光 |

## 6. 光照和色调

推荐基础：

- 主光：太阳/月光方向光。
- 环境光：低强度，避免洞穴全黑。
- 局部魔法光：只给灵脉、火种、神器、阵眼、Boss 关键技能。
- 色调映射：保持高亮资源不爆白。
- 雾：用于区域氛围和远距裁剪，但不能遮住敌我轮廓。

场景光照规则：

| 场景 | 主光 | 特殊处理 |
| --- | --- | --- |
| 王冠草原 | 柔和日光 | 道路和资源弱高亮 |
| 月纹山脊 | 冷光 | 月纹钢、月影剑用冷边光 |
| 灵脉湿地 | 青色局部光 | 水体不用灵脉青主色，灵脉单独发光 |
| 星砂荒丘 | 暖夜光 | 星砂夜间闪烁，白天降亮度 |
| 黑金王座 | 低环境 + 王冠金线 | 王座、神器、火种优先可读 |

## 7. 角色可读渲染

角色渲染要表达状态，而不是只展示皮肤。

| 状态 | 可视规则 |
| --- | --- |
| 轻装 | 轮廓窄，跑动拖尾短，脚步尘线轻 |
| 中载 | 背包和侧挂明显，转向动画更重 |
| 重载 | 肩背大件、步幅变短、疾跑蓄势视觉变慢 |
| 超载 | 不显示疾跑风线，动作下沉 |
| 持王权火种 | 余烬橙拖痕和周期脉冲，不能完全隐藏 |
| 持全局唯一神器 | 黑金外圈和专属副色，远距星冠提示 |
| 保护期 | 半透明圆盾，不可被误认为结界技能 |
| 倒地 | 身体低位，队友救援提示，不用血腥堆砌 |

## 8. 剑术 VFX

剑术必须优雅、短促、可读。

| 动作 | VFX | 时长 | 规则 |
| --- | --- | --- | --- |
| 轻击 | 细剑弧，低亮 | 0.12-0.18s | 只表达方向，不遮挡人 |
| 突刺 | 直线银光或风线 | 0.10-0.16s | 强调距离和命中点 |
| 重击 | 更宽弧线 + 起手聚光 | 0.25-0.35s | 前摇明显，给对手反应 |
| 完美招架 | 短冷闪 + 火花/符线 | 0.12s | 声音和画面都清晰 |
| 闪步 | 残影一帧到三帧 | 0.20s | 不做长时间隐身 |
| 破阵 | 地面裂光沿剑路展开 | 0.35s | 只在阵眼/结界互动时强化 |

流派色彩必须遵守《美术风格与色彩规范》：月影剑月银，王庭剑王冠金，灰烬剑余烬橙，风歌剑绿青。

## 9. 法术 VFX

法术要有明确三段：前摇、释放、残留。

| 阶段 | 视觉 | 技术 |
| --- | --- | --- |
| 前摇 | 手部符文、脚下小法阵、目标地提示 | mesh circle + 透明材质 |
| 释放 | 弹道、结界、冲击、根须或风线 | billboard、ribbon、简单 mesh |
| 残留 | 地面灼痕、霜纹、灵脉波、结界裂纹 | decal 或覆盖层实体 |

法术可读规则：

- 敌方法术前摇使用敌意红描边或危险形状。
- 友方法术不使用敌意红。
- 范围法术必须先显示落点或边界。
- 控制法术必须显示剩余时间或衰减。
- 灵视类效果只给轮廓，不把屏幕刷成青色。

## 10. 火种与神器渲染

### 10.1 王权火种

王权火种必须像战略目标，不像普通掉落。

表现规则：

- 掉落状态：地面有余烬橙竖向微光和小范围灰烬环。
- 携带状态：角色背后或手持位置有拖痕，每隔一段时间脉冲。
- 远距提示：小地图火焰形图标，世界中只给模糊方向，不给精确透视。
- 保护限制：不能被普通箱子、草丛或皮肤完全遮蔽。

### 10.2 全局唯一神器

神器是实体，不是背包图标。

表现规则：

- 统一黑曜底 + 王冠金外圈 + 专属副色。
- 持有者有明显负担表现：行动尾迹、身上裂光或小范围环境响应。
- 激活时全局广播，但世界内只显示合理范围内的视觉。
- 封印时需要圆环刻度、读条、打断反馈。

神器 VFX 优先级高于普通法术，但不能遮挡敌我读招。

## 11. 地形与资源渲染

地形不直接改底图，而是渲染覆盖层。

| 类型 | 渲染做法 |
| --- | --- |
| 挖沟 | 低位 mesh + 暗边 + 碰撞同步 |
| 筑墙 | 模块化墙段 mesh，受击裂纹材质 |
| 道路 | 地表 decal 或薄 mesh，边缘磨损 |
| 木桥 | 模块化板件，断裂状态有替换 mesh |
| 符文槽 | 暗槽 mesh，激活后按资源色发光 |
| 阵眼 | 圆环刻度 mesh + 进度材质 |
| 灾变污染 | 地面裂纹 decal + 粉红暗脉冲 |

资源节点和采矿槽必须有采集弱点视觉：

- 树：树纹亮边。
- 石：裂线三段。
- 地表矿物：矿脉细线。
- 矿坑槽位：槽口矿线、弱点闪点、粉尘和枯竭裂纹。
- 灵质：脉冲环。
- 星砂：夜间粒子闪点。

## 12. 相机与视角

对战支持第一/第三人称切换，但渲染系统统一用状态驱动。

| 视角 | 用途 | 渲染重点 |
| --- | --- | --- |
| 第一人称 | 采集、剑术细节、施法瞄准 | 手部、武器、法阵前摇、交互轮廓 |
| 第三人称 | PVP、搬运、团队战、地形改造 | 角色轮廓、敌我、地面范围、周围动作 |
| 战略地图 | 国家指挥、标点、火种/神器追踪 | 抽象图标、区域、路线 |
| 经营视角 | 家具摆放、社交、活动 | 舒适光照、低战斗噪声 |

相机规则：

- 近战命中不强行晃到失控。
- 被击中可有短促反馈，但不能影响招架判断。
- 低血量不做大面积红屏，改用边缘脉冲和音效。
- 负重和疾跑用 FOV 微变化，但幅度小。

## 13. 小地图与世界标记

高价值目标使用颜色、形状、节奏三重编码。

| 目标 | 世界表现 | 小地图表现 |
| --- | --- | --- |
| 敌方玩家 | 敌意红短描边，仅在规则允许时显示 | 红尖角 |
| 友方玩家 | 友方绿圆环 | 绿圆点 |
| 王权火种 | 余烬拖痕、模糊方位 | 橙火焰慢脉冲 |
| 全局唯一神器 | 黑金星冠脉冲 | 金星冠强脉冲 |
| 阵眼 | 圆环刻度和进度 | 环形进度 |
| 危险区域 | 半透明边界和斜纹 | 红橙边界 |
| 资源节点 | 近处描边，远处不刷屏 | 图标按筛选显示 |
| 矿坑模块 | 入口和高价值槽位常显低强度轮廓 | 只显示模糊矿区或被侦测槽位 |
| 洞穴模块 | 已发现入口常显轮廓，未发现不显示 | 洞穴显影事件后显示模糊入口 |
| 神器材料 | 携带和掉落都有短脉冲 | 持有者撤离时显示模糊拖痕 |

## 14. 性能预算

| 项目 | 高配 | 低配 |
| --- | --- | --- |
| 角色高模距离 | 25m | 15m |
| 中模距离 | 60m | 40m |
| 远距替身 | 120m | 80m |
| 同屏高质量剑轨 | 20 条 | 8 条 |
| 同屏普通粒子源 | 80 个 | 30 个 |
| 动态局部光 | 24 个 | 8 个 |
| 高质量透明法阵 | 12 个 | 4 个 |
| 地形覆盖层可见块 | 256 | 128 |

降级优先级：

1. 降普通环境粒子。
2. 降远处角色材质。
3. 降非关键法术残留。
4. 降局部光和阴影。
5. 保留敌我、火种、神器、危险区和当前交互目标。

## 16. 验收标准

- 30 人混战中，玩家能分清敌我、火种持有者、神器持有者和危险区。
- 轻击、突刺、重击、招架和施法前摇在第三人称下可读。
- 灵脉、水体、普通资源不会颜色混淆。
- 全局唯一神器远看像神器，近看能区分是哪一件。
- 地形覆盖层和真实碰撞状态一致。
- 低配降级后仍保留核心玩法提示。
- 渲染系统不写入权威生命、资源、装备、神器和地形状态。

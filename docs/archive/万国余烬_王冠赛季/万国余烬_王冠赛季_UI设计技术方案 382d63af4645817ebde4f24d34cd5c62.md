# 万国余烬：王冠赛季 UI设计技术方案

**版本**：V2.0 重构设计版

**适用范围**：HUD、小地图、背包、装备、地形工具、国家指挥、经营世界 UI、Bevy UI 实现

**最后更新**：2026-06-17

**文档定位**：本文件定义 UI/UX 和技术实现边界。颜色和图标遵守《美术风格与色彩规范》，权威状态来自服务端 Snapshot。

---

## 1. UI 设计目标

UI 要解决四个问题：

- **我现在安全吗**：保护期、PVP 状态、危险区、敌人、怪物、污染。
- **我能做什么**：采集、开箱、搬运、建造、施法、招架、封印。
- **代价是什么**：耐力、法力、材料、时间、声音暴露、死亡掉落。
- **目标在哪里**：王权火种、神器、阵眼、国家任务、资源线。

UI 不能像 MMO 那样把屏幕堆满技能栏。战斗时简洁，操作时展开，指挥时切地图，经营时舒适。

---

## 2. UI 技术原则

- UI 只读 `Snapshot`、本地预测缓存和配置表。
- UI 只发送 `IntentMsg`，不能写权威 ECS 组件。
- 高风险操作必须二次确认或强提示。
- 所有颜色必须同时配形状，不能只靠颜色。
- 小地图和世界标记必须支持筛选，避免资源图标刷屏。
- 公开赛和经营世界 UI 必须明确显示“经营资产不提供战斗数值”。

## 3. Bevy UI 插件拆分

```rust
pub struct EmberUiPlugin;

impl Plugin for EmberUiPlugin {
    fn build(&self, app: &mut App) {
        app.add_plugins((
            HudPlugin,
            MinimapUiPlugin,
            InventoryUiPlugin,
            EquipmentUiPlugin,
            TerrainToolUiPlugin,
            CaveRogueUiPlugin,
            NationCommandUiPlugin,
            ArtifactUiPlugin,
            CrownWorldUiPlugin,
            UiIntentBridgePlugin,
        ));
    }
}
```

| 插件 | 职责 |
| --- | --- |
| `HudPlugin` | 生命、耐力、法力、负重、阶段、保护、PVP |
| `MinimapUiPlugin` | 小地图、火种、神器、阵眼、危险区、任务标点 |
| `InventoryUiPlugin` | 背包、堆叠、掉落、交易、容器 |
| `EquipmentUiPlugin` | 装备槽、耐久、属性来源、维修 |
| `TerrainToolUiPlugin` | 地形改造模式、预算、材料、失败原因 |
| `CaveRogueUiPlugin` | 洞穴入口、房间进度、Boss 召唤、神器材料路线、撤离风险 |
| `NationCommandUiPlugin` | 国家成员、任务、补给、据点、战略地图 |
| `ArtifactUiPlugin` | 神器持有、激活、负担、反制、封印 |
| `CrownWorldUiPlugin` | 家具、皮肤、活动、治理权、社交等级 |
| `UiIntentBridgePlugin` | UI 操作转 `IntentMsg` |

```rust
#[derive(Resource)]
pub struct UiViewState {
    pub active_panel: Option<UiPanel>,
    pub map_mode: MapMode,
    pub inventory_context: InventoryContext,
    pub selected_entity: Option<Entity>,
}

#[derive(Component)]
pub struct UiReadsSnapshot;

#[derive(Message)]
pub struct UiIntentMsg {
    pub intent: ClientIntent,
}
```

UI 数据流：

```
Server Snapshot / Local Prediction
  -> UiModelBuildSystems
  -> Bevy UI Nodes
  -> Player Click / Hotkey
  -> UiIntentMsg
  -> Client Net Intent
  -> Server Authority
```

## 5. 主 HUD

HUD 默认只显示战斗必要信息。

| 区域 | 内容 | 显示规则 |
| --- | --- | --- |
| 左下 | 生命、耐力、法力 | 常驻，低血/低耐有轻提示 |
| 中下 | 当前手持物、剑术/法术状态 | 战斗或操作时显示 |
| 右下 | 交互提示、快捷操作 | 接近目标时显示 |
| 左上 | 队友和国家简况 | 可折叠，受击/倒地强提示 |
| 右上 | 小地图和阶段计时 | 常驻 |
| 顶部 | 全局事件、火种/神器公告 | 只在重要事件出现 |
| 屏幕边缘 | 危险方向、受击方向、污染/风暴 | 短暂提示 |

禁止：

- 常驻 20 个技能按钮。
- 大面积红屏。
- 用弹窗挡住招架和施法前摇。
- 把经营通知推到公开赛战斗中。

---

## 6. 生命、耐力、法力、负重

| 指标 | 表现 |
| --- | --- |
| 生命 | 红色不大面积铺屏，使用条形和边缘脉冲 |
| 耐力 | 绿色或浅金条，疾跑蓄势时出现分段充盈 |
| 法力 | 灵脉青条，只有可施法时强化 |
| 负重 | 背包图标 + 轻装/中载/重载/超载状态 |
| 疾跑满势 | 耐力条上方出现小型速度刻度 |
| 受击断势 | 疾跑刻度断开，短灰色冷却 |

负重 UI 必须显示实际后果：

- 疾跑蓄势变慢。
- 闪避变差。
- 是否不能疾跑。
- 大件携带时哪些动作被禁用。

## 7. 交互 UI

交互提示必须说清楚风险。

| 行为 | UI 内容 |
| --- | --- |
| 采集 | 产物、工具、预计时间、声音半径、弱点提示 |
| 开箱 | 开启时间、可打断、陷阱风险、声音提示 |
| 拾取火种 | 必掉落、暴露半径、不能安全存放 |
| 拾取神器 | 必掉落、负重、脉冲暴露、单人限制 |
| 建国仪式 | 材料、读条、公告风险、可被打断 |
| 封印神器 | 材料、时间、全图公告、失败损失 |
| 地形改造 | 预算、材料、尺寸、关键路径冲突 |
| 进入洞穴 | 洞穴类型、预计长度、入口暴露、撤离条件 |
| 召唤 Boss | 召唤材料、读条、提示半径、失败损失、可打断 |
| 携带神器材料 | 指向神器、重量、死亡必掉落、是否会留下光痕 |

高风险交互使用短确认，不使用长篇说明。确认按钮文案必须带风险词，例如“携带火种”而不是“确认”。

## 8. 背包与装备 UI

背包不是仓库页游格子，而是运输风险界面。

### 8.1 背包

| 元素 | 规则 |
| --- | --- |
| 格子 | 显示体积和堆叠 |
| 重量 | 显示当前 W / 上限 W |
| 大件 | 不进普通格子，显示在携带区 |
| 掉落 | 标出全掉落、部分掉落、必掉落 |
| 腐坏 | 食物显示腐坏计时 |
| 声音 | 高噪声物品或开箱行为有声音提示 |

### 8.2 装备

| 槽位 | UI |
| --- | --- |
| 主手 | 当前剑具/工具，耐久 |
| 副手 | 盾/法器，格挡或法术属性 |
| 身体 | 防护、重量、动作惩罚 |
| 披肩 | 法抗、灵视、身份装饰 |
| 背部 | 背包、大件、火种支架 |
| 法器 | 法术环、调灵叉、测镜 |
| 神器 | 只在持有时显示，不作为普通装备栏 |

装备属性要显示来源拆解，例如基础、装备、负重、状态、神器负担，防止玩家看不懂数值变化。

## 9. 小地图与战略地图

小地图默认显示：

- 自己和队友。
- 当前阶段边界。
- 近期危险方向。
- 任务标点。
- 火种和神器模糊提示。

战略地图用于国家指挥：

| 功能 | 规则 |
| --- | --- |
| 标点 | 攻击、防守、集合、运输、撤退 |
| 路线 | 商队路线、火种护送、地形通路 |
| 资源筛选 | 木石、矿物、灵质、遗迹、Boss |
| 洞穴层 | 已发现入口、队友所在房间、撤离点、召唤脉冲 |
| 地形层 | 墙、沟、桥、道路、阵眼 |
| 战争层 | PVP 区域、危险区、国家核心 |

小地图高价值图标规则：

- 王权火种：橙火焰，慢脉冲。
- 全局唯一神器：金星冠，强脉冲。
- 阵眼：环形进度。
- 敌方：红尖角。
- 友方：绿圆点。

## 10. 地形工具 UI

地形工具必须像“工程工具”，不是自由涂鸦。

模式：

- 挖沟。
- 筑墙。
- 架桥。
- 修路。
- 符文槽。
- 阵眼基座。
- 拆除/修复。

每个模式显示：

- 材料成本。
- 预算占用。
- 尺寸限制。
- 施工时间。
- 是否阻挡关键路径。
- 失败原因。

预览颜色：

| 状态 | 颜色 |
| --- | --- |
| 可建造 | 友方绿 |
| 材料不足 | 星砂黄警告 |
| 预算不足 | 王冠金警告 |
| 禁区/关键路径 | 敌意红 |
| 需要国家权限 | 王冠金锁图标 |

## 11. 洞穴、Boss 与神器材料 UI

洞穴 UI 不是传统副本面板。它只服务一次短链路：进去、判断、押注、撤离。

| 状态 | UI |
| --- | --- |
| 发现入口 | 显示洞穴类型、入口危险、预计房间数，不显示完整地图 |
| 进入洞穴 | 顶部小型房间链：入口、未知房间、已探索房间、撤离点 |
| 采矿房 | 显示采矿槽噪声、过采风险、洞窟空壳警戒 |
| 宝箱房 | 显示开箱读条、陷阱概率等级、声音半径 |
| 机关房 | 显示机关进度、失败反馈、是否触发守卫 |
| 祭坛房 | 显示召唤材料缺口、读条、提示范围、失败损失 |
| Boss 战 | 显示阶段、可反制目标、低血量脉冲倒计时 |
| 撤离 | 显示最近出口、队友携带材料、追踪光痕剩余时间 |

神器材料 UI 必须同时显示两条唤醒路线：

| 路线 | UI 表达 |
| --- | --- |
| 量路线 | 残片、星砂、灵质、遗迹核心等进度条，显示还差多少 |
| 珍稀路线 | 专属材料槽位，显示来源洞穴/Boss 和携带风险 |

禁止：

- 把洞穴画成完整大地图，导致玩家把它理解成安全副本。
- 把专属材料显示成“已获得神器”。
- 在 Boss 战中用大弹窗遮挡读招、招架和法阵边界。
- 只显示掉落概率，不显示撤离和死亡掉落风险。

## 12. 神器 UI

神器 UI 要把它当“公共战略事件”，不是个人装备。

| 状态 | UI |
| --- | --- |
| 现世 | 全图公告 + 模糊方位 |
| 掉落 | 小地图强脉冲，世界星冠提示 |
| 被持有 | 持有者负担、暴露倒计时、可激活状态 |
| 激活 | 技能名、范围、反制窗口 |
| 被反制 | 震荡状态和冷却 |
| 封印中 | 圆形读条、打断提示、材料风险 |
| 已封印 | 王座进度或战略收益展示 |

神器 UI 不能显示为普通装备词条加成。必须显示战略代价：重量、暴露、封印、争夺。

## 13. 国家与队伍 UI

国家 UI 只显示决策必要信息。

| 面板 | 内容 |
| --- | --- |
| 成员 | 在线、倒地、距离、当前任务 |
| 任务 | 集合、护送、修路、守阵眼、探洞、召唤 Boss |
| 建筑 | 国家核心、剑阁、符文塔、秘仪工坊状态 |
| 补给 | 食物、水、材料、大件运输 |
| 情报 | 斥候、灵视塔、火种/神器模糊情报 |
| 战争 | 敌方据点、PVP 热点、终局王座 |

国王/指挥权限只影响标点和建设权限，不给战斗数值。

---

## 14. 经营世界 UI

经营世界 UI 可以更温柔，但要和对战 UI 分离。

模块：

- 家具摆放。
- 皮肤衣柜。
- 公共区治理。
- 活动发布。
- NPC 配置。
- 店铺陈列。
- 社交等级。
- 历史荣誉。

关键规则：

- 进入公开赛前显示公平性提示：经营资产不带入战斗数值。
- 皮肤详情标注“仅外观”。
- 活动门票或资格不能显示成战斗增益。

## 15. 输入与快捷键

| 操作 | 默认输入 | 规则 |
| --- | --- | --- |
| 交互 | E | 接近目标显示 |
| 背包 | I | 战斗中可打开但不暂停 |
| 装备 | Tab / I 子页 | 快速换装有读条或限制 |
| 地图 | M | 小地图展开 |
| 地形工具 | B | 需要工具或权限 |
| 洞穴概况 | C | 仅在洞穴内或入口附近显示 |
| 标点 | 鼠标中键 | 按住打开环形菜单 |
| 神器能力 | 特殊键位 | 只在持有时显示 |
| 取消读条 | 移动/右键/Esc | 清晰反馈 |

## 16. UI 组件规范

| 组件 | 规则 |
| --- | --- |
| 图标按钮 | 用图标优先，文字只补充危险操作 |
| 条形状态 | 生命、耐力、法力、读条 |
| 分段条 | 疾跑蓄势、阵眼进度、封印进度 |
| 房间链 | 洞穴短链路、已探索房间、撤离点 |
| 角标 | 掉落规则、腐坏、稀有度 |
| Tooltip | 显示来源、代价、风险 |
| Toast | 短事件：拾取、掉落、完成 |
| Banner | 全局事件：神器现世、王座显形 |
| Radial Menu | 标点和快速指令 |
| Modal | 仅用于高风险确认 |

---

## 17. 验收标准

- 玩家能在 5 秒内理解当前 PVP 状态和保护状态。
- 玩家拾取火种或神器前能明确知道死亡必掉落和暴露风险。
- 背包能清楚显示负重、格子、大件和掉落规则。
- 地形工具能显示为什么不能建造。
- 小地图能区分火种、神器、阵眼、敌方、友方和危险区。
- 洞穴 UI 能显示房间进度、召唤风险、材料路线和撤离方向。
- UI 不直接修改权威组件，只发送 Intent。
- 经营世界 UI 不暗示任何公开赛战斗数值收益。

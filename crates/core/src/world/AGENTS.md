# 世界所有权

此目录负责世界标识、时间、持久状态、事件、记忆、空间查询和初始生成。

- 世界包含大气、水、植物、动物和玩家干预；它不等同于地形。
- 将地形后端保持在稳定的世界查询之后。
- 通过一个世界生成入口点路由所有初始构建。
- 将当前地形管线、内容生成器、覆盖层和 `WorldGenerator` 视为待统一的迁移来源，而不是并行的永久 API。
- 不要在此处添加仅客户端的装饰或资源路径。

## 当前锚点

- `generate_world(WorldConfig)` 统一应用 preset、seed、出生平台和可选内容物化；不要从客户端另建初始世界。
- `World` 同时支持程序化地形、编辑覆盖层和物化内容；空间查询应优先依赖稳定的 `World` API。

# 万国余烬：王冠赛季 经营世界设计案

**版本**：V2.0 重构设计版

**适用范围**：王冠经营世界、治理权更替、社交等级、家具、皮肤、活动、身份与公开赛边界

**最后更新**：2026-06-18
**文档定位**：本文件是经营世界（王冠季节）的玩法主文档。经营世界提供公开活动赛排名之外的社交、展示、活动运营和身份认同场景。**经营资产不得提供任何战斗数值**，具体资产硬数据以《表格包》第 15 节为准，状态机与事件以《蓝皮书》第 1、3 节为准，Bevy 实现以《Bevy 0.18 架构实现》第 17、22 节为准。

## 0. 一句话定位

王冠经营世界是一座 **"在公开活动赛之间" 持续运转的中长期社交经营场所**：玩家在这里获得展示、社交、活动组织、身份认同和下一赛季的参赛资格，但这里不会给单局任何一枪、一剑、一颗灵质带来加成。

经营世界不创造战斗优势。它的核心价值是：

- 让公开活动赛的胜利"有地方可兑现"。
- 给落败玩家保留回归入口。
- 用治理权、活动、社交和身份把零散单局连接成"王冠季节"叙事。
- 用持续运营奖励留住非高强度对战玩家。

## 1. 设计原则（七条铁律）

经营世界必须遵守的七条不可逾越的线：

1. **零战力污染**：经营资产不能携带进入对局影响伤害、血量、耐力、法力、负重、资源、装备、秘剑谱、法术环、神器或复活次数。任何字段尝试写入战斗 modifier 都必须在 `ApplySocialAsset` 中以 `assert combat_effect == none` 拦截并审计告警。
2. **零强绑定**：玩家即使完全放弃经营世界，也可以正常进入公开活动赛。经营世界只影响**报名资格**与**展示**，不影响对局内表现。
3. **个人资产神圣不可侵犯**：治理权更替、公共区被新治理者改写、个人家具被擦除、个人称号被覆盖，都构成"破坏"。经营系统必须保证：失去治理权 ≠ 失去个人资产。
4. **治理权可被替换但不能被垄断**：治理周期有上限、继任规则透明、单治理周期不能转赠或永久持有。
5. **公开身份优先**：公开活动赛用公开身份结算；匿名赛不进王冠世界治理链。王冠世界只奖励公开参赛者。
6. **展示优于炫耀**：皮肤、家具、称号、入场动画的设计目标是"我能一眼分辨这个人/房间/国家的风格"，而不是"我比所有人都显眼"。显眼必须先通过可读性闸口。
7. **PVP 可读性闸口**：任何可能进入对局视野的视觉资产（剑饰、法术皮肤、入场动画、称号框）都必须能通过 PVP 可读性闸口：不得伪装敌我、不得改变剑长判读、不得遮蔽火种/神器/危险区描边。

## 2. 经营世界结构

### 2.1 三个空间层

经营世界分三个空间层，分别承担不同玩法密度：

| 空间层 | 视角 | 主要内容 | 玩法密度 |
| --- | --- | --- | --- |
| **公共区** | 俯视/等距 | 王座厅、活动广场、商队驿站、广场集市、灵灯街 | 高密度社交与活动 |
| **个人区** | 等距/俯视 | 个人房间、公共楼层、小型摊位、社交等级奖励房间 | 中密度自我展示 |
| **活动区** | 俯视为主 | 治理者组织活动期间的临时场地（赛跑场、谜题屋、装饰大赛、社交大会） | 周期密度峰值 |

三个空间层共享一个货币系统、身份系统和事件时间表，但治理权只对公共区产生直接修改权限，对个人区只产生"广播"或"展示位"权。

### 2.2 公共区的固定承载

公共区是经营世界的核心。它的承载点包括：

- **王座厅**：当前治理者的核心舞台、王冠雕像、王座、活动主持台。
- **活动广场**：可临时搭台的主广场，用于治理者主办活动和大型社交聚会。
- **商队驿站**：玩家租用摊位、发布护送任务、提供交易场所的中立区。
- **广场集市**：低门槛的露天摊位，所有玩家可短期租用。
- **灵灯街**：社交密度最高的街区，集中各种装饰、家具展示和聊天节点。

每个固定承载点都有**承载容量**和**占用预算**。治理者可以**重命名**和**重新布置**它们，但不允许**物理删除**。

### 2.3 个人区

每个玩家拥有 **1 间主房间 + 1 块小型公共楼层**。主房间是个人区核心，用于展示个人家具、皮肤、称号、历史荣誉和活动奖励。公共楼层是个人区的"对外窗口"，用于短期主题装扮、小型展览和社交展示。

个人区的容量按社交等级解锁，等级越高房间越大、可展示家具越多。

## 3. 玩家旅程

### 3.1 入场与离场

玩家进入经营世界的标准路径：

1. 完成一场公开活动赛（或匿名赛练习结束）。
2. 通过主菜单进入"王冠世界"入口。
3. 自动加载或更新个人区、公共区当前状态。
4. 进入公共区作为起点。

退出路径：

- 返回主菜单。
- 进入下一场对局（公开活动赛/匿名赛），自动清空对局内意图。
- 离线（自动保存个人资产和社交等级）。

### 3.2 典型循环

| 阶段 | 玩家动作 | 系统反馈 |
| --- | --- | --- |
| 公共活动赛结束 | 收到治理权、称号、奖励邮件 | 治理权/称号/家具入账 |
| 进入经营世界 | 进入公共区 | 公告："X 已接任本期治理者" |
| 自由探索 | 逛摊位、社交、装扮个人区 | 社交经验+、展示排名+ |
| 报名下一场 | 点击"报名公开赛" | 资格券入账或扣减 |
| 下一场公开赛 | 离开经营世界 | 经营世界继续运作（治理者负责） |

经营世界不允许"备战"。它不允许提供战斗加成、练习场模拟、入局前装备预览。玩家只能做社交与展示。

## 4. 治理权与替换

### 4.1 治理权来源

治理权由 **公开活动赛排名** 决定：

- 每场公开活动赛结束，按排名结算 `OnPublicEventScoreChanged`。
- 单赛季累计分最高者获得下一周期治理权。
- 治理权是 **运营席位**，不是永久私产。

### 4.2 治理周期

- **治理周期**：默认 2 周，配置范围 1-4 周（见《表格包》第 4 节 `crown_governance_cycle`）。
- **替换时点**：周期结束当日 24:00，按"上一周期最后一场公开活动赛累计分"结算新治理者。
- **同分处理**：取最近一场公开活动赛贡献分最高者；若仍同分，由治理委员会随机分配（保底机制）。

### 4.3 治理权权限

治理者拥有以下权限（只能对公共区生效）：

| 权限 | 范围 | 上限 |
| --- | --- | --- |
| 公共区编辑 | 广场、街道、灵灯街装饰 | 每周期预算封顶（治理预算池） |
| 公共设施布置 | 王座厅重命名、广场主题色 | 不能删除承载点 |
| 活动发布 | 活动广场、商队驿站、谜题屋 | 每周期最多 N 场活动（按配置） |
| NPC 配置 | 活动主持、商店 NPC | 受治理预算池限制 |
| 集市摊位规划 | 摊位布局、租金 | 必须在公共规则上限内 |
| 公共皮肤展示 | 王座皮肤、广场皮肤 | 受可读性闸口限制 |
| 公共区广播 | 文字公告、推送 | 每周期配额 |

### 4.4 治理权不可做的

治理者不能：

- 删除任何玩家的个人家具、个人房间、个人称号、个人皮肤、个人奖励。
- 没收任何玩家通过合法活动获得的资产。
- 为自己或他人发放任何形式的战斗装备、火种、神器、灵质、符文石、月纹钢、王座碎片或秘仪材料。
- 改变公开活动赛规则或匹配规则。
- 影响下一场对局的伤害、血量、装备、资源、复活、秘剑谱、法术环、秘仪研究、神器掉落或建国权获取概率。

所有上述行为在《蓝皮书》伪逻辑 4.14 `AssignCrownGovernance` 与 4.15 `ApplySocialAsset` 中由服务端权威系统强制拦截。

### 4.5 治理权替换流程

新赛季治理权更替按以下流程执行：

```
公开活动赛排名结算
  -> 累积分排名
  -> 检查同分保底
  -> Emit OnCrownGovernanceAssigned(world_id, new_governor_id, cycle_id)
  -> 系统保留旧治理者个人资产
  -> 系统交接公共区编辑权给新治理者
  -> 公共区变更对所有玩家公告
```

旧治理者：

- 保留个人家具、个人房间、个人称号、个人皮肤、个人奖励。
- 保留社交等级。
- 失去公共区编辑权、活动发布权、NPC 配置权。
- 保留历史治理者徽章（不可重新激活）。

新治理者：

- 获得公共区编辑权（N 周期预算池）。
- 获得活动发布权（按周期配额）。
- 获得 NPC 配置权（受预算池限制）。
- 可继承或重置前任留下的公共区装饰（默认继承）。

---

## 5. 失去治理权的保障

失去治理权不是毁灭。系统必须保证玩家保留：

- 所有个人家具、个人房间、个人摆设。
- 所有个人皮肤、个人称号、个人表情、个人入场动画。
- 社交等级和社交经验。
- 历史治理者徽章（一次性，不可重复激活）。
- 活动奖励历史记录。
- 公开活动赛资格。

玩家失去的：

- 当前周期的公共区编辑权。
- 当前周期的官方活动发布权。
- 当前周期的治理者身份标识。

治理权更替不会触发任何形式的资源清算、社交关系断裂、个人成就擦除或公共摊位回收（玩家自租摊位独立计算）。

## 6. 社交等级

### 6.1 社交等级定位

社交等级是经营世界的核心进度。它提供：

- 个人区容量提升（房间更大、家具更多）。
- 社交能力解锁（表情、名片格式、入场动画、社交称号）。
- 公共区展示位（解锁高级展示墙、公共橱窗）。

社交等级 **绝对不提供**：

- 入局血量、耐力、法力、负重加成。
- 入局伤害、暴击、招架加成。
- 入局资源、装备、秘剑谱、法术环、秘仪加成。
- 入局复活次数、复活速度加成。
- 匹配权重、匹配优先级、地图优势。

### 6.2 社交经验来源

社交经验（Social XP）来自非战斗行为：

| 来源 | 经验值（默认） | 说明 |
| --- | --- | --- |
| 参加活动 | 50-300 / 场 | 治理者活动、社交大会、节日 |
| 完成社交挑战 | 30-150 / 项 | 摆放、布置、装扮、解谜 |
| 装修个人房间 | 20 / 房间完成 | 房间主题达成度 |
| 装修公共楼层 | 30 / 楼层完成 | 公共楼层达成度 |
| 经营摊位 | 5 / 笔交易 | 上限 200 / 天 |
| 为他人提供社交帮助 | 10-30 / 次 | 装饰协助、任务解答 |
| 节日活动参与 | 100-500 / 节 | 特殊节日翻倍 |

### 6.3 社交等级解锁

| 等级 | 解锁内容 |
| --- | --- |
| L1 | 1 间基础主房间、基础表情、基础名片 |
| L2-L4 | 主房间扩容、5 个新表情 |
| L5-L7 | 公共楼层解锁、3 个入场动画 |
| L8-L10 | 公共橱窗解锁、社交称号池扩展 |
| L11-L14 | 主题房间解锁、稀有入场动画 |
| L15+ | 限定称号、解锁高级展示墙 |

社交等级上限与赛季挂钩，可由配置表调整。

## 7. 家具系统

### 7.1 家具来源

家具来源于非战斗途径：

| 来源 | 稀有度 | 限制 |
| --- | --- | --- |
| 公开活动赛奖励 | 普通-稀有 | 仅限活动赛季排位 |
| 经营世界商店 | 普通 | 用社交币购买 |
| 节日活动 | 普通-史诗 | 节日限定 |
| 治理者赠礼 | 史诗 | 治理周期内限 1 次 |
| 老玩家回归 | 普通 | 限定渠道 |

家具**不能**通过：

- 单局对局获得。
- 充值直接购买。
- 用经营资产与战斗资源互换。
- 在公开赛内用任何单局资源兑换。

### 7.2 家具分类

| 类别 | 用途 | 示例 |
| --- | --- | --- |
| 装饰类 | 视觉装饰 | 烛台、花瓶、壁画、地毯 |
| 功能类 | 解锁互动 | 留言板、签到本、商店柜 |
| 主题类 | 房间主题 | 余烬主题、星井主题、月夜主题 |
| 公共类 | 公共区装饰 | 灵灯、王座雕像、广场摆件 |
| 活动类 | 活动现场布置 | 舞台、谜题屋、颁奖台 |

### 7.3 家具规则

- 家具永久属于玩家个人，不能交易（除商店直购外）。
- 家具仅在个人区或玩家自有摊位展示，不进入公共区（除非治理者主动布置并消耗治理预算）。
- 家具不能提供战斗效果（assert combat_effect == none）。
- 家具在治理权更替中**不被清除**。

## 8. 皮肤系统

### 8.1 皮肤范围

皮肤涵盖以下视觉系统：

- 角色整体外观（轮廓色、剪影、服饰）。
- 武器外观（剑柄、剑鞘、收剑动作、持握特效装饰）。
- 法术外观（粒子色、轨迹色、装饰性表现）。
- 入场动画（公开赛入场、对局开场、公告展示）。
- 称号框（名称板、勋章框、赛季横幅）。
- 头像框与名片格式。

### 8.2 PVP 可读性闸口

任何可能进入对局视野的皮肤都必须能通过 PVP 可读性闸口：

- 不得伪装敌我（不得把敌方阵营配色完全相同化）。
- 不得改变剑长判读、剑轨可读性。
- 不得遮蔽火种、神器、危险区描边。
- 不得让友方或敌方身份在混战中混淆。
- 法术皮肤不得改变危险范围、爆炸范围、读条提示的视觉读法。

可读性闸口失败时，皮肤进入"对局禁用列表"，玩家可在个人区展示，但不能带进对局。

### 8.3 皮肤不可改变的属性

皮肤不能改变：

- 攻击判定距离。
- 视野范围。
- 实际伤害值。
- 攻击冷却或施法冷却。
- 移动速度。
- 血量上限。
- 资源采集效率。
- 招架窗口、完美招架窗口、闪避距离。
- 入局初始装备、初始资源、初始法力。

皮肤仅改变装饰性表现：颜色、装饰粒子、入场动作、特效色调、称号框样式。

### 8.4 皮肤来源

| 来源 | 稀有度 | 限制 |
| --- | --- | --- |
| 公开活动赛排名 | 史诗 | 赛季限定 |
| 节日活动 | 稀有 | 节日限定 |
| 社交等级奖励 | 普通-稀有 | 等级解锁 |
| 经营世界商店 | 普通 | 社交币购买 |
| 治理者赠礼 | 史诗 | 治理周期内限 1 次 |

## 9. 活动运营

### 9.1 治理者活动

治理者可在每周期内发布最多 N 场（按配置）官方活动：

| 活动类型 | 描述 | 奖励 | 备注 |
| --- | --- | --- | --- |
| 家具展览 | 公共区展示玩家家具 | 社交经验 + 限定称号 | 评分由治理者或玩家投票 |
| 战旗纪念会 | 历史战旗与称号展览 | 历史荣誉展示 | 治理者可投票选最佳战旗 |
| 装饰大比拼 | 个人区装饰评分 | 限定家具 + 称号 | 全员投票或系统评分 |
| 皮肤大赏 | 皮肤展示 | 皮肤券 + 限定头像 | 公开身份玩家参与 |
| 摊位集 | 临时公共摊位 | 摊位经营税优惠 | 鼓励社交交易 |
| 节日活动 | 特殊节日运营 | 限定家具 + 称号 + 表情 | 节日周期 |
| 王冠模拟 | 历史王座复盘 | 历史称号 | 治理者主持历史战役模拟 |

### 9.2 治理者活动规则

- 活动奖励只能是家具、皮肤、称号、社交经验、活动币、限定入场动画。
- 活动奖励**不能**包含战斗装备、火种、神器、灵质、符文石、月纹钢、王座碎片、秘仪材料、复活次数或任何入局优势。
- 活动不能影响下一场公开活动赛的伤害、血量、装备、资源、秘剑谱、法术环或秘仪研究速度。
- 治理者不得利用活动为个人或联盟谋取战斗优势。

### 9.3 公共活动

非治理者玩家也可以组织 **个人活动**：

- 个人活动使用玩家个人楼层或临时租用公共摊位。
- 个人活动不能直接占用公共区固定承载点（除非治理者授权）。
- 个人活动奖励规模受个人楼层承载容量限制。

### 9.4 节日与跨季节活动

节日活动是预定的跨季节运营事件。它们：

- 由全局运营系统统一发布，不依赖治理者。
- 节日限定家具、皮肤、称号在节日期间投放。
- 节日活动奖励遵守上述零战力污染原则。

## 10. 经济系统

### 10.1 货币

经营世界使用 **社交币**（Social Coin）和 **活动币**（Event Token）：

| 货币 | 用途 | 来源 | 限制 |
| --- | --- | --- | --- |
| 社交币 | 商店、摊位经营、个人升级 | 活动、社交行为、经营收益 | 不能兑换战斗资源 |
| 活动币 | 节日限定、跨季节活动 | 节日活动、特殊成就 | 不能兑换战斗资源 |

社交币和活动币都不能：

- 兑换为单局战斗资源。
- 兑换为局内灵质、符文石、月纹钢、食物、纤维、矿物。
- 兑换为局内装备或秘剑谱。
- 直接影响公开活动赛入局匹配或对战结果。

### 10.2 摊位与税收

公共摊位租金按广场类型分档：

| 摊位 | 位置 | 租金（社交币 / 周期） | 容量 |
| --- | --- | --- | --- |
| 广场集市 | 露天广场 | 50 | 4 件 |
| 商队驿站 | 驿站固定铺位 | 120 | 8 件 |
| 灵灯街 | 街边铺位 | 80 | 6 件 |
| 活动摊位 | 临时活动场 | 30 | 3 件 |

摊位租金归 **公共区预算池**，由治理者用于活动、装饰和运营。摊主交易抽取 5% 经营税注入公共池。

税收不能用于：

- 私人馈赠。
- 治理者私人资产。
- 战斗装备采购。

### 10.3 捐赠

玩家可向公共池自愿捐赠家具、皮肤、活动币。捐赠后：

- 该资产进入公共区或活动池。
- 治理者可以重新布置。
- 捐赠者失去该资产的私人所有权，但保留历史捐赠记录（称号、勋章）。

捐赠不能换取代币、局内资源或战斗优势。

## 11. 称号与身份

### 11.1 称号来源

| 来源 | 称号 |
| --- | --- |
| 公开活动赛排名前 3 | 赛季冠/亚/季军 |
| 曾任治理者 | 历史治理者徽章 |
| 社交等级 | 等级称号 |
| 节日活动 | 节日限定称号 |
| 历史功勋 | 战斗称号（如"火种护送者"、"遗迹探险者"） |

### 11.2 称号展示规则

称号展示在三个地方：

- 经营世界个人资料卡。
- 公开活动赛公开身份牌。
- 对局内名称板（仅展示公开身份的称号，不展示经营私人称号）。

战斗称号（"火种护送者"等）只能反映该场公开活动赛内实际行为，**不能跨场累计**或被经营系统赋予。

### 11.3 身份系统

身份系统聚合玩家的：

- 公开身份（公开活动赛用的实名身份）。
- 匿名身份（匿名赛用的临时身份）。
- 治理者身份（仅在治理周期内有效）。
- 历史治理者身份（永久历史记录，不激活权限）。
- 社交等级身份（永久但可升级）。
- 节日身份（节日期间限定）。

每种身份在自己的范围内有效，**不交叉污染**。例如治理者身份不能赋予公开活动赛任何优势，匿名身份不能继承历史治理者称号。

## 12. 与公开活动赛的双向连接

### 12.1 对局进入规则

玩家进入公开活动赛前，系统执行以下检查：

```
can_enter_public_match(player):
    return player.public_event_ticket > 0
        OR player.public_event_score > ranking_threshold
        OR player.governance_active
```

注意：治理权**不**自动赋予入场资格，只在治理周期内给治理者 **1 张/周期 的资格券**（`permit_public_stall` 等同治理权限，详见《表格包》第 15 节）。

### 12.2 对局结束回流

公开活动赛结束后回流到经营世界的内容：

| 项目 | 来源 | 处理 |
| --- | --- | --- |
| 公开活动赛积分 | 排名结算 | 累加到赛季总分 |
| 历史称号 | 单局成就 | 进入称号池 |
| 战斗称号 | 当场行为 | 仅本场展示，赛后清除 |
| 战绩 | 战斗记录 | 进入公开履历 |
| 排名 | 排名结算 | 影响治理权候选 |

回流内容**不能**包含战斗装备、资源、秘剑谱、法术环、神器、火种或任何局内优势。

### 12.3 经营世界对下一场对局的影响

经营世界**不能**：

- 在玩家入局时携带任何加成。
- 改变入局初始血量、耐力、法力、负重、装备、资源、秘剑谱、法术环、秘仪、神器或建国权获取概率。
- 影响匹配权重、匹配优先级或地图选择。
- 影响公开赛内任何资源、装备、神器、秘剑谱、法术环或秘仪的获取速度或概率。
- 让皮肤改变战斗判读（受 PVP 可读性闸口限制）。

经营世界**可以**：

- 决定玩家是否有资格券进入公开活动赛。
- 展示玩家的历史称号、皮肤、家具。
- 在对局外运营活动、商店、社交和身份。

## 13. 公平性铁律（再扩展）

经营世界与公开活动赛之间有一道不可逾越的"公平墙"。这道墙的实现包括：

### 13.1 服务端权威闸口

- 所有经营资产在 `ApplySocialAsset` 中由 `assert combat_effect == none` 强制拦截。
- 所有 `SocialAsset.combat_effect` 字段在表格包校验阶段必须为 `none`，违反则在配置加载时报警。
- 所有公共活动奖励在 `CrownWorldService` 中由"奖励白名单"过滤：只允许发放列入白名单的非战斗资产。

### 13.2 客户端审计

- 客户端 UI 不得展示来自经营资产的伤害加成、血量加成、冷却缩短或资源加成。
- 客户端预测不得写入任何来自经营资产的修饰符。
- 客户端皮肤不得修改对局内判读、距离、范围、冷却、伤害或资源采集。

### 13.3 数据审计

- 经营世界日志必须可审计：每笔社交币、活动币、家具、皮肤的来源、流转和归属必须记录。
- 治理权更替必须记录：旧治理者、新治理者、周期 ID、时间戳、保留资产清单。
- 任何 `combat_effect != none` 的经营资产尝试注册必须报警并隔离。

### 13.4 反作弊

- 经营世界与对局之间不允许任何形式的 RPC 注入。
- 经营世界不允许提供"备战场"或"练习模拟"：所有公共活动赛练习仅在匿名赛进行。
- 经营世界不允许提供战斗数据预览、对手装备预览、地图情报或战术预演。
- 经营世界的所有交互必须经过服务端权威验证，客户端不能伪造交易、活动、捐赠或社交经验。

## 14. 数据结构参考

经营世界相关数据结构在《蓝皮书》第 1.5（CrownWorld）和第 1.6（SocialAsset）节定义：

- `CrownWorld`：当前治理者、治理周期 ID、公共布局状态、活动日历、社交金库、治理历史。
- `SocialAsset`：资产 ID、所有者、类型（家具/皮肤/称号/表情/房间主题）、装饰标签、交易状态、`combat_effect: always_none`。

经营世界事件在《蓝皮书》第 2 节：

- `OnCrownGovernanceAssigned`：排名结算后分配治理权。
- `OnCrownGovernanceReplaced`：治理权替换，保留个人资产。
- `OnSocialAssetGranted`：经营资产发放。
- `OnPublicEventScoreChanged`：公开赛计分，影响治理权候选。

状态机在《蓝皮书》第 3.4 节：

- `CrownGovernanceState`：Unassigned → Assigned → Replaced → Archived。

## 15. MVP 验收

### 15.1 首发必须实现

- 公开活动赛排名结算并写入 `PublicEventScore`。
- 排名触发 `OnCrownGovernanceAssigned` 事件。
- 治理周期倒计时与替换时点。
- 个人房间布置 MVP（家具摆放、主题应用）。
- 公共区基础布局（王座厅、广场、灵灯街可见，不可编辑）。
- 公共摊位租用与交易。
- 治理者公共区编辑权 MVP（重命名、调色、装饰布置）。
- 节日活动一档 MVP（家具展览或装饰大比拼）。
- 社交等级与社交经验。
- 称号与个人资料卡。
- 历史治理者徽章。
- 经营活动币与社交币。
- 治理权替换保留个人资产（强校验）。

### 15.2 验收硬门槛

- 治理权更替不删除任何个人资产。
- 经营资产入局不携带任何战斗 modifier。
- 皮肤不改变 PVP 可读性。
- 活动奖励不包含任何战斗资产。
- 公共活动赛入局资格可由资格券和赛季分独立授予。
- 经营世界与对局之间无任何隐藏 RPC。
- 客户端 UI 不展示来自经营资产的战斗修饰符。
- 所有经营资产流转记录可审计。

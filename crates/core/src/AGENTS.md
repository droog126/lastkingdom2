# 共享模拟核心

此模块负责离线和在线游戏共享的权威、确定性自然世界模型。

## 方向

- 建模从大气和水到植物和动物的因果链。
- 将渲染、输入设备、资源加载、流程编排和传输适配器保持在此 crate 之外。
- 提供一个统一的模拟步骤，供服务器、离线权威、场景和确定性测试使用。
- 将地形表示视为可替换的空间数据；不要将体素方块作为游戏的定义。

## 迁移

- 现有模块仍然是有效的迁移来源。仅通过有针对性的测试和调用点追踪来移动行为。
- 在迁移旧的 `world`、`creature`、`monster`、`ecology` 或 `sim` 行为时，不要引入第二套规则实现。
- 保持资源核算、确定性、协议兼容性和离线/在线一致性。

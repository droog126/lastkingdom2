# 万国余烬：王冠赛季 开发顺序与里程碑

**版本**：V2.0 重构设计版

**适用范围**：Bevy 0.18 MVP 开发顺序、阶段目标、验收门槛、禁止事项

**最后更新**：2026-06-17

**文档定位**：本文件定义从 0 开始开发的顺序。原则是先做可运行权威闭环，再做表现，再做内容量。不要先做完整美术、经营世界或复杂神器。

---

## 0. 总原则

开发顺序必须围绕一个目标：

> 尽快做出一局可以开始、移动、采集、战斗、改造地形、争夺火种、建国、摧毁核心并结束的最小可玩闭环。
> 

优先级：

1. 权威模拟。
2. 角色控制。
3. 插值同步。
4. 资源循环与矿坑模块。
5. 基础战斗。
6. 地形覆盖层。
7. 对局闭环。
8. 王权火种与建国。
9. 探索层。
10. 肉鸽洞穴、Boss 召唤和神器材料。
11. 法术、秘剑、神器。
12. UI、渲染和程序化美术升级。
13. 公开赛和经营世界。

禁止一开始做：

- 完整经营世界。
- 大量角色皮肤。
- 复杂神器。
- 大规模 POI 内容。
- 完整怪物生态。
- 自由体素地形。
- 精美 UI 全套。
- 复杂联网大厅。

## 1. 阶段 P0：工程骨架

**目标**：Bevy 0.18 项目能启动，客户端和 Headless 服务端都能跑。

**要做**：

- 建立 workspace：`ember_shared / ember_game / ember_client / ember_server`。
- 建立 `EmberGamePlugin`。
- 建立 `AppState`、`MatchState`。
- 建立 `SimSet` 和 `PresentationSet`。
- 设置 `FixedUpdate` 30Hz。
- 建立 `GameTables`。
- 加载最小配置：生命、耐力、移动速度、资源 ID。

**不要做**：

- 不做真实美术资产。
- 不做复杂 UI。
- 不做多人网络。
- 不做战斗。

**验收门槛**：

- `ember_client` 能启动一个空场景。
- `ember_server` 能以 headless 模式启动。
- 控制台能打印当前 AppState 和 MatchState。
- 配置加载失败会明确报错。

---

## 2. 阶段 P1：本地角色控制

**目标**：一个玩家能在本地地图里顺滑移动。

**要做**：

- 玩家实体。
- 胶囊体碰撞。
- 第三人称相机。
- WASD 移动。
- 鼠标视角。
- 行走、小跑、疾跑起步、疾跑蓄势、满势疾跑。
- 耐力消耗和恢复。
- 轻装/重载/超载状态。
- 基础 Debug UI：速度、耐力、负重、当前状态。

**不要做**：

- 不做复杂动画。
- 不做装备外观。
- 不做网络同步。
- 不做战斗伤害。

**验收门槛**：

- 玩家能移动、转向、跳/越小障碍。
- 疾跑需要蓄势，不是按下立刻满速。
- 重载会明显影响疾跑蓄势。
- 超载不能疾跑。
- 相机不会穿入地面或疯狂抖动。

---

## 3. 阶段 P2：插值与预测同步

**目标**：先把 30Hz 权威模拟和高帧渲染桥搭好，避免后面所有系统返工。

**要做**：

- `SimTransform`。
- `RenderProxy`。
- authority entity / visual entity 分离。
- 本地 visual transform 插值。
- 远端 `SnapshotBuffer`。
- 2-3 tick 插值延迟。
- 最多 3 tick 外推。
- 三档纠偏：小误差平滑、中误差快速修正、大误差 snap。
- Debug overlay：权威位置、可视位置、预测误差、snap 次数。

**不要做**：

- 不做完整网络大厅。
- 不做复杂回滚战斗。
- 不做真实匹配系统。

**验收门槛**：

- 30Hz 模拟下，60/120/144 帧渲染都不台阶式跳动。
- 本地移动输入不等服务端回包。
- 远端假实体在快照流里平滑移动。
- 预测误差能被纠偏。

---

## 4. 阶段 P3：资源循环

**目标**：玩家能采集、携带、掉落，资源能被审计。

**要做**：

- 低产资源节点。
- 矿坑模块原型。
- 采矿槽。
- 采集工具。
- 采集时间。
- 采集弱点。
- 采集声音/暴露半径。
- 矿坑资源池扣除。
- 矿坑枯竭状态。
- 背包格子。
- 重量。
- 大件携带。
- 掉落物。
- 死亡全掉落的基础逻辑。
- `ResourceDeltaMsg` 和资源池审计。

**不要做**：

- 不做所有资源种类。
- 不做复杂洞穴。
- 不做自由挖矿。
- 不做完整商队。
- 不做高级配方。

**验收门槛**：

- 玩家能砍树、采石、采灵质。
- 玩家能在一个矿坑模块中占槽采矿。
- 采矿产出从矿坑资源池扣除并产生声音暴露。
- 资源进入背包并增加重量。
- 超重影响移动。
- 死亡后资源掉落。
- 资源变化能写审计日志。

---

## 4.1 阶段 P3.5：矿权争夺原型

**目标**：验证“找到高爆率位置持续挖矿，然后运输出去”的核心循环。

**要做**：

- `MiningSite`。
- `MiningSlot`。
- 露天矿坑模块 1 种。
- 稳采/强采模式。
- 采矿声音半径。
- 矿坑堆料点。
- 手推车或肩扛运输。
- 采矿被攻击中断。
- 矿坑枯竭三阶段。

**不要做**：

- 不做多层地下城。
- 不做真实坍塌物理。
- 不做 6 种矿坑全量。
- 不做玩家自定义矿洞路线。

**验收门槛**：

- 两队玩家会自然围绕同一个矿坑发生争夺。
- 留人守矿和全员采矿有明显取舍。
- 矿物重量迫使玩家护送或分批运输。
- 强采更快但更容易暴露或触发危险。

---

## 5. 阶段 P4：基础战斗

**目标**：有可用但不复杂的剑术战斗。

**要做**：

- 生命。
- 受击。
- 倒地。
- 轻击。
- 突刺。
- 重击。
- 格挡。
- 招架。
- 耐力消耗。
- 硬直。
- 武器扫掠命中。
- 动作输入缓冲。

**不要做**：

- 不做完整秘剑流派。
- 不做大法术。
- 不做神器。
- 不做复杂连招。

**验收门槛**：

- 两个玩家本地/局域测试能互相攻击。
- 格挡能降低伤害或消耗耐力。
- 招架窗口能触发短反击机会。
- 耐力不足会限制连续战斗。
- 命中判定不依赖视觉剑轨单帧。

---

## 6. 阶段 P5：地形覆盖层

**目标**：玩家能改变局部战场，但不能破坏地图可玩性。

**要做**：

- 木墙。
- 石墙。
- 浅沟。
- 短桥。
- 道路。
- 符文槽占位。
- 地形改造预算。
- 材料消耗。
- 客户端预览。
- 服务端确认后生成正式覆盖层。
- 关键路径保护。
- 坑洞逃生：走坡、翻越、攀爬点、搭桥、填沟。
- `StuckProbe` 和受限自动脱困。

**不要做**：

- 不做自由体素。
- 不做大型地下洞穴。
- 不做复杂坍塌物理。

**验收门槛**：

- 玩家能建墙、挖浅沟、架桥、修路。
- 客户端预览不参与碰撞。
- 服务端拒绝封死关键路径。
- 玩家掉进坑里至少有一种逃生方式。
- 火种/神器不能被丢进不可达坑。

---

## 7. 阶段 P6：对局流程

**目标**：匿名赛能从开始跑到结束。

**要做**：

- 对局创建。
- 开局保护期。
- 中途加入保护。
- 阶段计时。
- PVP 开关。
- 简单出生点。
- 简单淘汰。
- 简单胜利条件。
- 对局结束界面。

**不要做**：

- 不做公开赛排名。
- 不做经营世界。
- 不做复杂观战。

**验收门槛**：

- 一局能开始。
- 保护期不能互相伤害。
- 保护期结束后能 PVP。
- 一方被淘汰后能结束。
- 对局可重复开。

---

## 8. 阶段 P7：王权火种与建国

**目标**：核心国战目标出现。

**要做**：

- 王权火种生成。
- 火种拾取。
- 火种携带暴露。
- 火种死亡必掉落。
- 火种不可安全存放。
- 建国仪式。
- 国家核心。
- 国家成员。
- 国家核心被摧毁。
- 国家灭亡后火种部分回流。

**不要做**：

- 不做复杂外交。
- 不做长期公会。
- 不做国家科技树完整版。

**验收门槛**：

- 玩家能抢火种。
- 火种持有者死亡后火种掉落。
- 玩家能用火种建国。
- 敌方能摧毁国家核心。
- 国家灭亡后火种回流到战局。

---

## 9. 阶段 P8：探索层

**目标**：地图不只是采集点，而有宝箱、POI、怪物和风险选择。

**要做**：

- 普通宝箱。
- 高价值宝箱。
- 开箱读条。
- 开箱打断。
- 掉落表。
- 2-3 种 POI。
- 2-3 种小怪。
- 1 个 Boss 原型。
- POI 关键路径保护。

**不要做**：

- 不做几十种怪物。
- 不做完整 Boss 演出。
- 不做所有 POI。

**验收门槛**：

- 玩家能进入 POI。
- 宝箱能开出局内资源。
- 高价值宝箱会制造暴露风险。
- 怪物能守资源或宝箱。
- Boss 能掉落火种或稀有材料。

---

## 9.1 阶段 P8.5：肉鸽洞穴与神器材料

**目标**：让洞穴成为“奇遇、召唤、Boss、神器材料”的高风险短链路。

**要做**：

- `CaveModule`。
- `CaveRoom`。
- 3-5 房间短链。
- 洞穴入口发现。
- 1 种奇遇式 Boss。
- 1 种召唤式 Boss。
- `BossSummonSite`。
- 召唤材料锁定和打断损失。
- 神器残片。
- 1 种专属神器材料。
- 神器量路线和珍稀路线进度。
- 洞穴撤离风险提示。

**不要做**：

- 不做大型地下城。
- 不做多层迷宫。
- 不做所有 Boss。
- 不做随机词条 Boss。
- 不做长期洞穴进度。

**验收门槛**：

- 玩家能发现并进入一个洞穴。
- 洞穴有 3 个以上房间。
- 探索能触发奇遇式 Boss。
- 玩家能投入材料召唤 Boss。
- Boss 能掉落神器残片或专属神器材料。
- 专属材料死亡必掉落，且会暴露撤离路线。
- 神器唤醒能读取量路线或珍稀路线进度。

---

## 10. 阶段 P9：秘剑、法术、神器

**目标**：进入奇幻核心，但仍保持可控。

**要做**：

- 1 条秘剑路线。
- 1 条法术路线。
- 法术预览。
- 吟唱。
- 打断。
- 法力消耗。
- 简化结界。
- 1-2 件全局唯一神器。
- 神器量路线唤醒。
- 神器珍稀材料路线唤醒。
- 神器现世公告。
- 神器拾取、激活、掉落。
- 神器封印。

**不要做**：

- 不做 10 个流派。
- 不做复杂天赋树。
- 不做随机词条神器。

**验收门槛**：

- 秘剑能改变战斗方式，而不是只加伤害。
- 法术有前摇、范围、消耗和打断。
- 神器不是普通装备，死亡必掉落。
- 神器能改变战略目标，但不能直接变成无脑碾压。

---

## 11. 阶段 P10：UI、渲染、程序化美术升级

**目标**：让核心闭环可读、好看、可调。

**要做**：

- HUD。
- 背包 UI。
- 装备 UI。
- 地形工具 UI。
- 小地图。
- 火种/神器提示。
- 资源节点程序化变体。
- 矿坑模块入口、采矿槽和枯竭表现。
- 地形覆盖层程序化美术。
- 剑轨。
- 法阵。
- 基础描边。
- LOD 和 VFX 预算。

**不要做**：

- 不做最终商业化 UI。
- 不做大量皮肤。
- 不做全套过场动画。

**验收门槛**：

- 玩家知道当前阶段和 PVP 状态。
- 玩家知道背包重量、掉落风险和高价值物风险。
- 玩家知道矿坑品级、采矿声音风险和枯竭状态。
- 玩家能看懂地形工具失败原因。
- 混战中能读敌我、火种、神器和危险区。
- 低配降级后仍能玩。

## 12. 阶段 P11：公开赛与经营世界

**目标**：把单局胜负接到长期经营，但不破坏公平性。

**要做**：

- 公开活动赛入口。
- 公开赛计分。
- 排名结算。
- 治理权分配。
- 王冠经营世界入口。
- 家具摆放 MVP。
- 皮肤展示 MVP。
- 活动发布 MVP。
- 治理权替换。

**不要做**：

- 不做经营战斗数值。
- 不做长期装备带入。
- 不做复杂商业系统。
- 不做摧毁个人资产。

**验收门槛**：

- 公开赛能结算排名。
- 排名能分配或替换治理权。
- 经营资产不影响下一场战斗。
- 失去治理权不会删除个人资产。

## 13. 最小可玩版本定义

第一版真正可玩的 MVP 应该满足：

- 玩家能进匿名赛。
- 能移动、疾跑、负重、采集。
- 能背包、掉落、死亡掉落。
- 能基础剑术战斗。
- 能建墙、挖沟、架桥、修路。
- 掉坑能逃生。
- 能争夺王权火种。
- 能建国。
- 能摧毁国家核心。
- 能结算胜负。

如果这些没有完成，不应该投入大量时间做经营世界、美术皮肤、复杂神器和大型 Boss。

## 14. 推荐提交节奏

每个阶段至少分 3-8 个小提交，不要大爆炸提交。

推荐提交粒度：

- `chore: create bevy workspace`
- `feat: add fixed simulation sets`
- `feat: add player movement`
- `feat: add sprint charge`
- `feat: add render proxy interpolation`
- `feat: add resource gathering`
- `feat: add inventory weight`
- `feat: add basic melee combat`
- `feat: add terrain edit preview`
- `feat: add terrain edit authority commit`
- `feat: add sovereign spark pickup`
- `feat: add nation founding`

每次提交前至少跑：

- 格式化。
- 单元测试。
- 目标模块集成测试。
- 一次手动冒烟测试。

## 15. 阶段门禁

| 阶段 | 不满足这些就不要进下一阶段 |
| --- | --- |
| P0 | client/server 不能同时启动 |
| P1 | 移动和相机手感不稳定 |
| P2 | 30Hz 模拟下高帧渲染仍抖动 |
| P3 | 资源不能审计或重量不生效 |
| P3.5 | 高产矿物还是普通散点，或矿坑不能产生争夺 |
| P4 | 战斗没有耐力和硬直约束 |
| P5 | 地形能封死关键路径或坑不能逃 |
| P6 | 对局不能完整开始和结束 |
| P7 | 火种不能掉落/回流 |
| P8 | POI 不能产生风险选择 |
| P8.5 | 洞穴只是采矿点，或 Boss 不能产出神器材料 |
| P9 | 神器只是数值装备 |
| P10 | UI 看不懂目标和风险 |
| P11 | 经营资产影响战斗 |

---

## 16. 第一周建议

如果从今天开始开发，第一周不要碰美术和大型玩法。

第一周只做：

1. Bevy workspace。
2. `FixedUpdate` 30Hz。
3. 配置加载。
4. 玩家胶囊移动。
5. 第三人称相机。
6. 疾跑蓄势。
7. 耐力。
8. 负重状态占位。
9. `SimTransform` / `RenderProxy` 最小插值。

第一周结束时，应该能得到一个非常朴素但手感方向正确的角色控制原型。

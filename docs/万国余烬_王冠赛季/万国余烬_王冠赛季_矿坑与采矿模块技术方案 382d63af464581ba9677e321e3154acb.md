# 万国余烬：王冠赛季 矿坑与采矿模块技术方案

**版本**：V2.0 重构设计版

**适用范围**：矿坑、洞穴、深层矿脉、采矿槽、采矿爆率、资源池、运输、PVP 热点、Bevy 0.18 实现

**最后更新**：2026-06-17

**文档定位**：本文件是《地形系统技术方案》《地形高度与地表加料技术方案》《资源循环与地形改造》的专项补充。它明确：采矿不是无限挖地形，而是争夺高产资源模块。

---

## 1. 核心结论

挖矿的玩法本质是：

> 找到一个爆率高、产量稳定、风险也高的地方，持续占位开采，再把重资源安全运出去。
> 

因此 MVP 不做“玩家把山挖穿”的全体素矿洞。矿坑、洞穴、灾变矿潮和遗迹采石场都应实现为 **MiningSiteModule**：

- 它是服务端生成的玩法模块。
- 它挂在 Base Terrain 或 POI 上。
- 它有有限资源池、采矿槽、产出权重、枯竭状态和危险状态。
- 它可以被守卫、争夺、封锁、修路、架桥、布防。
- 它不允许玩家无限向下挖，也不允许生成不可逃脱地下空间。

---

## 2. 玩法目标

矿坑要承担四件事：

1. 形成中期 PVP 热点。
2. 提供战争资源的高产来源。
3. 让运输、护送和伏击变得自然。
4. 让地形系统保持可控，不滑向无限沙盒。

矿坑不是单个矿石节点。它更像一个可争夺的小型据点：

- 有入口。
- 有采矿槽。
- 有噪声和小地图线索。
- 有怪物或环境危险。
- 有堆料点、推车点和出口路线。
- 有枯竭和阶段变化。

## 3. 模块类型

| 模块ID | 名称 | 主要产出 | 风险 | 玩法定位 |
| --- | --- | --- | --- | --- |
| `mine_surface_pit` | 露天矿坑 | 石料、铁、铜 | 声音暴露、无遮挡 | 早中期抢矿点 |
| `mine_cave_fissure` | 裂隙洞穴 | 铁、银、符文石 | 洞窟空壳、视野差 | 小队深入采矿 |
| `mine_moon_ridge` | 月纹矿坑 | 月纹钢、银 | 夜间高产、白天低效 | 秘剑路线核心 |
| `mine_spirit_sink` | 灵脉矿井 | 灵质、符文石 | 灵压脉冲、污染 | 法术路线核心 |
| `mine_relic_quarry` | 遗迹采石场 | 石料、铜、遗迹核心碎片 | 符文守卫、机关 | 建筑和秘仪路线 |
| `mine_calamity_bloom` | 灾变矿潮 | 灵质、铁、灾变晶核 | 污染、环境伤害 | 高收益事件矿 |

地表低产露头仍可存在，但只负责早期过渡和路线提示。真正高产资源必须进入矿坑模块。

## 4. 单个矿坑的玩法循环

```
发现矿坑
  -> 灵视/勘测判断品级
  -> 清理入口或守卫
  -> 占用采矿槽
  -> 连续采矿提高效率
  -> 噪声/灵压/粉尘暴露位置
  -> 装袋或装车
  -> 护送回营地/国家
  -> 矿坑枯竭或触发危险
```

玩家每次进入矿坑都要回答：

- 继续挖，还是带着已有矿石撤？
- 多人一起挖提高产量，还是留人守入口？
- 修路和架桥提高运输，还是隐藏路线降低暴露？
- 强采赌高爆率，还是稳采降低塌方、怪物和污染？

## 5. 采矿槽

采矿槽是矿坑内部的交互点。玩家不是对任意墙面挥镐，而是在合法槽位上开采。

| 槽类型 | 人数 | 产出 | 风险 | 说明 |
| --- | --- | --- | --- | --- |
| 普通槽 | 1 | 主矿 + 石料 | 低 | 适合早期单人或双人 |
| 富矿槽 | 1 | 主矿高权重 | 中 | 会产生更明显声音 |
| 共振槽 | 2 | 灵质/符文加权 | 中高 | 需要节奏配合 |
| 深层槽 | 2-3 | 稀有矿概率 | 高 | 需要清理守卫或加固 |
| 事件核心槽 | 3 | 晶核/火种碎片/神器残片概率 | 很高 | 触发局部提示 |

槽位数量决定矿坑吞吐量。高产矿坑不只是单人发财点，而是团队运营点。

## 6. 爆率与产出模型

“爆率高”不应做成完全随机赌狗。推荐用 **有限资源池 + 权重掉落 + 保底进度**。

```
yield_score =
  site_grade
  + slot_richness
  + tool_quality
  + weak_point_chain
  + team_sync_bonus
  - depletion_penalty
  - overmine_instability

roll yield_table by yield_score
cap by remaining_resource_pool
add pity_progress for rare drop if no rare result
```

规则：

- 每个矿坑有 `grade`，玩家可通过灵视测镜得到模糊品级。
- 每个槽有 `richness`，视觉上用矿线密度和颜色表现。
- 连续命中弱点提高效率，但同时提高噪声。
- 强采会提高短期产出和稀有权重，但增加污染、塌方、召怪或小地图暴露。
- 稀有矿不会无限刷。矿坑资源池不足时，爆率自动降级为普通副产。
- 保底只在矿坑本地资源池内生效，不能凭空创造超过资源总量表的稀有资源。

## 7. 风险模型

采矿暴露分三层：

| 风险 | 触发 | 表现 |
| --- | --- | --- |
| 声音 | 矿镐命中、矿车移动、塌方 | 近距离方向声和小地图短波 |
| 灵压 | 灵质、符文石、月纹钢采集 | 青/紫/月银脉冲，被灵视塔捕捉 |
| 战略提示 | 富矿槽、事件核心槽、灾变矿潮 | 局部 PVP 圈或模糊热点 |

危险事件：

- 洞窟空壳听声追踪。
- 落石打断采矿并伤害耐久。
- 灵脉污染让产出变高但回收率变低。
- 富矿槽过采后临时封槽。
- 月纹矿坑在夜间高产，但会产生更远月光提示。

## 8. 地形系统边界

矿坑可以看起来像洞穴，但技术上不是自由挖出的地下世界。

实现边界：

- 矿坑入口是 `TerrainModuleAnchor` 上的模块实体。
- 洞穴内部可用模块化房间或半开放剖面场景。
- 坑壁、矿线和采矿槽是玩法实体和表现层。
- 玩家可加固入口、修路、搭桥、布墙、刻符文槽。
- 玩家不能扩大矿坑边界、无限向下挖、开新地下路或封死唯一出口。

矿坑里的坑、裂隙和落差必须复用《可破坏地形与坑洞逃生技术方案》的 `EscapeAnchor`。

## 10. Bevy 插件与系统

```rust
pub struct MiningSitePlugin;

impl Plugin for MiningSitePlugin {
    fn build(&self, app: &mut App) {
        app.add_message::<MiningStartIntentMsg>()
            .add_message::<MiningYieldGrantedMsg>()
            .add_message::<MiningHazardTriggeredMsg>()
            .add_systems(FixedUpdate, (
                validate_mining_start.in_set(SimSet::ValidateRules),
                tick_mining_slots.in_set(SimSet::Interaction),
                resolve_mining_yield.in_set(SimSet::ResourceAndLoot),
                emit_mining_noise.in_set(SimSet::ResourceAndLoot),
                resolve_mining_hazards.in_set(SimSet::Combat),
                update_mining_depletion.in_set(SimSet::ScoreAndAudit),
            ));
    }
}
```

系统职责：

| 系统 | 职责 |
| --- | --- |
| `spawn_mining_sites_from_worldgen` | 根据世界生成结果创建矿坑模块 |
| `validate_mining_start` | 校验距离、工具、槽位、保护期、危险状态 |
| `tick_mining_slots` | 推进采矿进度、连击效率和不稳定度 |
| `resolve_mining_yield` | 从资源池扣除并发放产出 |
| `emit_mining_noise` | 产生声音、灵压和小地图模糊提示 |
| `resolve_mining_hazards` | 处理落石、污染、召怪、封槽 |
| `update_mining_depletion` | 更新枯竭、视觉阶段和审计 |

## 11. 网络同步

同步矿坑状态，不同步每一块石头。

| 数据 | 同步方式 |
| --- | --- |
| 矿坑生成 | seed + `MiningSiteSnapshot` |
| 槽位占用 | slot id + player id + progress |
| 产出 | 服务端权威 `MiningYieldGrantedMsg` |
| 噪声/灵压 | 事件消息 + 表现层 VFX |
| 枯竭 | depletion tier snapshot |
| 危险 | hazard event + 状态快照 |

客户端可以预测采矿动画和命中弱点反馈，但背包资源必须等服务端确认。

## 12. UI/UX

矿坑 UI 不应只显示“按 E 采矿”。它需要显示：

- 矿坑品级：贫、常、富、秘、灾变。
- 当前槽位类型。
- 预计主产出和可能副产，不显示精确隐藏权重。
- 噪声半径或灵压风险。
- 当前枯竭程度。
- 当前负重和撤离建议。
- 强采/稳采模式差异。

高价值槽位开始采矿时，应给队友和附近敌人可读信号，让“守矿”和“劫矿”成立。

---

## 13. 反滥用规则

- 保护期玩家不能占用富矿槽、深层槽和事件核心槽。
- 单个玩家不能同时占多个采矿槽。
- 采矿槽被占用后仍可被战斗打断。
- 矿坑入口不能被永久封死。
- 矿坑内掉落的王权火种、神器、Boss 残骸必须落到可达点。
- 断线玩家会释放槽位，背包资源按断线保护规则处理。
- 资源池枯竭后不能通过反复重进刷新产出。

## 14. MVP 范围

首发只做：

- 3 类矿坑：露天矿坑、裂隙洞穴、灾变矿潮。
- 每个矿坑 2-5 个采矿槽。
- 稳采和强采两种模式。
- 有限资源池扣除。
- 噪声半径和灵压脉冲。
- 枯竭三阶段视觉。
- 洞窟空壳或落石危险。
- 矿石重量、装车和运输。

暂缓：

- 复杂地下城。
- 真实坍塌物理。
- 玩家自定义矿洞路线。
- 多层地下导航网。
- 长期矿权经营。

---

## 15. 验收标准

- 玩家能找到矿坑、判断品级、占槽采矿并获得服务端确认的矿物。
- 高产矿坑比地表露头收益高，但会产生明显暴露。
- 矿坑资源池会枯竭，不能无限刷。
- 采出的矿物进入负重系统，运输会影响移动和战斗。
- 敌方能通过声音、灵压、入口路线或小地图模糊提示发现采矿活动。
- 矿坑不会改变 Base Terrain，不会生成不可逃脱洞穴。
- 所有矿物产出都写入资源池审计。

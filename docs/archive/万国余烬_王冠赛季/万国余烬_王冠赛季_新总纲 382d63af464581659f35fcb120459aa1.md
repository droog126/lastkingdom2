# 万国余烬：王冠赛季 新总纲

**版本**：V2.0 重构设计版

**适用范围**：产品定位、双层循环、事实源边界

**最后更新**：2026-06-17

**文档定位**：本总纲定义新方向。它推翻旧版“国家令牌商店、Base HP 复活税、神器堆数值、经营影响战力”的框架，保留有限资源循环、有限地形改造、肉鸽、经营与 PVP。

---

## 1. 一句话定位

《万国余烬：王冠赛季》是一款 **单局国战肉鸽 + 周期王冠经营世界** 的多人沙盒对抗游戏。

玩家在 40-60 人的公开或匿名战局中，从零开始争夺有限资源、建国权、秘剑谱、法术环、王权秘仪与全局唯一神器，经历从基础身法到优雅剑术、奇幻法术和国家级仪式的局内进化，最终统一战场。公开活动赛的胜者按排名获得下一周期的王冠经营世界治理权，在一个偏社交、家具、皮肤、活动运营的世界中经营声望和身份。

---

## 2. 必须保留的四个核心

### 2.1 有限资源循环

世界里的关键资源不是无限刷新的背景噪音，而是可追踪、可争夺、可回流的有限池。木材、矿物、灵质、符文石、星砂、建国权、秘剑谱、法术环与全局唯一神器都必须有来源、消耗和回流逻辑。

### 2.2 有限地形改造

玩家可以挖沟、筑垒、架桥、开辟阵眼、刻符、修路、布防和塑造法术战场，但不能无限造城或把地图改造成无法对抗的方块堡垒。地形改造是战术工具，不是绕过战争的万能答案。

### 2.3 单局肉鸽

每一局的地形、资源分布、奇遇、遗迹、全局事件、Boss、建国权刷新方式和胜利路径都变化。玩家要读局、应变、冒险，而不是背固定开局流程。

### 2.4 PVP 与经营并存

PVP 负责产生胜负、排名和王冠世界治理权。经营世界负责社交、展示、皮肤、家具、活动和身份。经营不提供伤害、血量、装备、复活、资源等战斗数值优势。

---

## 3. 双层循环

### 3.1 单局国战肉鸽

单局为 45-60 分钟，推荐 40-60 人。玩家入局后从零开始，前期采集、基础身法与简式剑术、临时结盟；中期争夺建国权、矿权、灵脉、秘剑谱、法术环和贸易路线；后期进入全局战争，王权秘仪、结界攻防、全局唯一神器和最终统一成为核心。

匿名赛用于练习和休闲，不影响排名，不产出王冠世界所有权。公开活动赛用于排名和王冠世界治理权更替。

### 3.2 王冠经营世界

公开活动赛排名决定王冠世界的周期性治理权。治理权不是永久私产，而是一个可被新赛季或新活动排名替换的运营席位。

经营世界玩法偏皮卡堂式社交经营：公共区域布置、家具收集、皮肤展示、活动举办、店铺与 NPC 配置、社交等级、称号和身份展示。

---

## 4. 公平性铁律

经营世界可以影响：

- 公开活动赛报名资格。
- 皮肤、家具、称号、头像框、入场动画。
- 世界治理权限、活动组织权、社交身份。
- 历史荣誉展示。

经营世界不得影响：

- 单局初始伤害。
- 单局初始血量。
- 单局初始装备。
- 单局复活次数。
- 单局资源数量。
- 单局秘仪研究速度。
- 单局建国权获取概率。

所有战斗资源必须在单局内重新获取。

---

## 5. 视角与操作

本作允许不同场景使用不同视角：

- 对局战斗：第一人称或第三人称可切换，强调采集、身法、剑术、施法、招架、法阵和地形改造。
- 国家指挥：临时战略地图或俯视指令界面，用于标点、任务、路线和情报。
- 王冠经营：俯视或等距视角，适合家具摆放、街区管理、活动运营和社交。

## 7. V2 MVP 边界

首发只做：

- 匿名赛。
- 公开活动赛。
- 单局保护期、中途加入保护、事件 PVP 和终局全图 PVP。
- 王权火种 / 建国权。
- 有限地形改造。
- 局内肉鸽地形、资源、事件和路线。
- 基础身法到秘剑、法术、王权秘仪的局内进阶。
- 王冠经营世界基础：社交等级、家具、皮肤、公共区治理、活动发布。

首发不做：

- 经营战斗数值加成。
- 公会永久战力继承。
- 复杂外交条约模拟。
- 长期装备带入公开赛。
- 摧毁他人个人资产。
- 旧版国家令牌商店和 Base HP 复活税。

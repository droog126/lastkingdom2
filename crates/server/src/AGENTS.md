# 服务器

此模块负责在线权威进程。

- 通过共享核心模拟步骤持有并推进权威世界。
- 验证玩家输入、持久化世界状态、复制相关快照和事件，并导出观察结果。
- 绝不依赖客户端渲染、相机、HUD、资源加载或美化模型代码。
- 逐步将行为从 `main.rs` 中移出，并在提取过程中保持当前网络兼容性。

## 当前锚点

- 自然模块由 `NatureServerPlugin` 组装；现有主服务器使用 `NatureServerProjectionPlugin` 把旧权威报告投影给新模块。
- 服务器仍同时承载旧的玩家、体素、PvP 和网络路径；自然迁移不能假设 `main.rs` 已经完全退役。

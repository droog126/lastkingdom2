# 开发与闭环控制

此模块负责持久的跨平台工作流自动化和观察-决策-执行契约。

- 启动和监督离线或在线运行，收集工件，评估断言，并报告健康状况。
- 将核心/服务器状态视为事实证据，将截图视为表现证据。
- 将工作流逻辑保留在 Rust 中；`justfile` 保持为简短别名。
- 除非当前文档和验证一起更新，否则保留现有的工件契约。

## 当前锚点

- `xtask` 提供 `scenario`、`health`、`audit-*`、`tdd` 和模型/内容辅助命令；持久编排逻辑放在 Rust 模块中。
- 健康判断先读取机器状态和日志，再结合截图；上一轮 `health.json` 为 `FAIL` 时不得直接开始下一轮视觉迭代。

# 万国余烬：王冠赛季 肉鸽洞穴与神器材料技术方案

**版本**：V2.0 重构设计版

**适用范围**：肉鸽洞穴、矿洞分支、奇遇式 Boss、召唤式 Boss、神器材料、神器唤醒路线、PVP 热点、Bevy 0.18 实现

**最后更新**：2026-06-17

**文档定位**：本文件补足“洞穴、矿洞、Boss、神器材料”的主玩法链。矿坑负责高产资源出口；洞穴负责肉鸽分支、奇遇、召唤仪式、Boss 战和神器材料跃迁。

## 1. 核心结论

洞穴不是大型地下城，也不是自由挖出来的地形。它是 **短副本式肉鸽模块**：

```
发现入口
  -> 进入 3-6 个房间的短链
  -> 采矿/宝箱/机关/奇遇/祭坛
  -> 触发奇遇式 Boss 或主动召唤 Boss
  -> 掉落神器材料、火种碎片、法术环、秘剑谱或高阶资源
  -> 搬运撤离并接受 PVP 风险
```

神器来源不应该只有“攒够残片点按钮”。V2 统一为两条路线：

- **量路线**：靠矿坑、宝箱、普通 Boss 和事件慢慢攒神器残片、星砂、灵质、遗迹核心。
- **珍稀材料路线**：靠洞穴奇遇 Boss 或召唤式 Boss 获取专属核心材料，显著缩短神器唤醒。

这让普通队伍能靠经营资源线稳步推进，也让冒险队伍能赌一场高风险 Boss 战改变局势。

---

## 2. 和矿坑模块的边界

| 模块 | 主要作用 | 产出逻辑 | 风险核心 |
| --- | --- | --- | --- |
| 矿坑模块 | 稳定产量、守矿、运输 | 有限资源池 + 采矿槽 + 枯竭 | 声音、灵压、运输、抢矿 |
| 肉鸽洞穴 | 分支探索、奇遇、Boss、神器材料 | 房间链 + 触发器 + 掉落表 | 迷路、机关、怪物、召唤暴露、撤离 |
| Boss 召唤点 | 把资源押注成高价值掉落 | 投入材料 + 仪式读条 + Boss 战 | 全局或局部提示、被偷袭、失败损失 |

矿坑可以作为洞穴的一个房间或入口，但矿坑不是洞穴全部。洞穴的关键不是持续产量，而是一次性高风险跃迁。

## 3. 洞穴生成原则

每局生成若干洞穴模块，但不全部公开。玩家通过灵视、地图线索、宝箱钥印、矿坑深层槽、Boss 痕迹或事件公告发现入口。

生成目标：

- 每局至少有 2-4 个普通洞穴。
- 每局至少有 1-2 个高价值洞穴。
- 洞穴长度控制在 5-10 分钟体验。
- 洞穴必须有明确出口、回撤路径或受限脱困机制。
- 洞穴奖励必须进入局内资源循环，不能产出长期战力。
- 高价值洞穴必须制造 PVP 交叉，不做安静刷本。

洞穴不追求大，而追求“每次进去都有一个问题”：

- 这条分支要不要走？
- 这个祭坛要不要献材料召唤？
- 现在带着材料撤，还是继续赌核心？
- 守入口还是深入打 Boss？
- 看到敌方进洞，要堵门还是尾随？

## 5. 洞穴房间结构

洞穴由房间模块拼接，不做自由地下世界。

| 房间类型 | 作用 | 风险 | 备注 |
| --- | --- | --- | --- |
| 入口房 | 进入、侦查、撤离 | 入口被伏击 | 必须有可读出口 |
| 分岔房 | 路线选择 | 错路耗时、敌方绕后 | 2-3 个出口即可 |
| 采矿房 | 高产采矿槽 | 声音暴露、洞窟空壳 | 复用 MiningSlot |
| 宝箱房 | 短读条奖励 | 开箱声音、陷阱 | 高价值箱给局部提示 |
| 机关房 | 解锁门或祭坛 | 读条、怪物刷新 | 适合遗迹洞穴 |
| 奇遇房 | 随机事件 | 奖励/危险二选一 | 触发奇遇 Boss |
| 祭坛房 | Boss 召唤 | 投入材料、暴露 | 可主动召唤 |
| Boss 房 | 战斗高潮 | PVE/PVP 夹击 | 必须防封门 |
| 撤离房 | 搬运离开 | 被追击、掉落 | 高价值材料要重 |

房间链推荐：

```
Entrance
  -> Branch
  -> Reward or Hazard
  -> Altar or Encounter
  -> Boss or Exit
```

## 6. Boss 两种来源

### 6.1 奇遇式 Boss

奇遇式 Boss 由探索触发，不要求玩家提前知道。

触发方式：

- 打开被封印的神器材料箱。
- 强采矿心槽到过载。
- 在奇遇房选择“取走遗物”。
- 进入旧王墓穴深处。
- 击破星井书页封线。

优点：

- 肉鸽惊喜强。
- 让洞穴不是纯路线背板。
- 适合掉落单件珍稀材料或神器残片。

限制：

- 不应在开局保护期触发。
- 不应在玩家无路可逃时触发。
- 不应生成在可被玩家永久封门的房间。

### 6.2 召唤式 Boss

召唤式 Boss 是主动押注。玩家把一批材料投入祭坛，开启读条，Boss 出现，同时附近玩家获得模糊提示。

召唤式 Boss 的价值在于：它把“资源经营”转化为“高风险跃迁”。

```
队伍攒材料
  -> 找到对应祭坛
  -> 投入召唤材料
  -> 局部公告和灵压提示
  -> Boss 战 + 玩家可能来抢
  -> 成功掉专属神器材料
  -> 失败损失部分材料并留下可抢掉落
```

召唤不是菜单按钮，而是地图上的公开行动。它必须能被侦测、打断、抢夺和尾随。

## 7. Boss 设计原则

Boss 不做刷经验机器。Boss 是路线转换器：

- 把普通资源转换成神器材料。
- 把洞穴探索转换成全局冲突。
- 把 PVE 风险转换成 PVP 机会。
- 把矿权、秘仪、法术、王权路线连接起来。

Boss 战要避免纯数值木桩：

| Boss 类型 | 玩法重点 | 反制 |
| --- | --- | --- |
| 矿心精英 | 破甲、落石、召洞窟空壳 | 分散站位、停采降噪 |
| 符文守门者 | 盾、机关、符文波 | 破坏符文柱 |
| 星井守书人 | 传送、法阵、星砂爆 | 打断读条、踩灭星盘 |
| 月下残影 | 招架、闪步、单挑压迫 | 控制、重载护卫 |
| 旧王残影 | 剑影、王座脉冲、火种诱导 | 破王冠锚点 |
| 黑日幼核 | 污染、驱散、区域压迫 | 净化、撤离、先破外壳 |

## 8. 神器材料体系

神器材料分三层：

| 层级 | 例子 | 来源 | 作用 |
| --- | --- | --- | --- |
| 通用量材料 | 神器残片、星砂、灵质、遗迹核心 | 矿坑、洞穴、宝箱、普通 Boss | 慢速唤醒神器 |
| 路线材料 | 王座碎片、灾变晶核、Boss 残骸、月纹钢 | 事件、召唤 Boss、洞穴深处 | 指定神器路线加速 |
| 专属珍稀材料 | 旧王冠骨、无鞘月刃、星井书页、无归旗钉、黑日核壳 | 奇遇 Boss 或召唤式 Boss | 大幅推进或指定唤醒某件神器 |

神器唤醒允许两种配法：

1. **量路线**：消耗大量通用量材料，时间长、暴露高，但不要求专属材料。
2. **珍稀路线**：消耗一个专属珍稀材料，加少量通用材料，速度快，但获取风险高。

这样不会出现“只有大公会能靠数量压死”，也不会让神器完全靠脸。普通队伍可以靠量，冒险队伍可以靠珍稀材料。

## 9. 神器材料和神器对应

| 神器 | 专属珍稀材料 | 主要来源 | 替代量路线 |
| --- | --- | --- | --- |
| 灰烬王冠 | 旧王冠骨 | 旧王墓穴、旧王残影召唤 | 神器残片 + 王座碎片 + 星砂 + 灵质 |
| 月下无鞘 | 无鞘月刃 | 月纹圣窟、月下残影奇遇 | 神器残片 + 月纹钢 + 银 + 星砂 |
| 星井法典 | 星井书页 | 星井深窟、星井守书人召唤 | 神器残片 + 星砂 + 遗迹核心 + 灵质 |
| 无归战旗 | 无归旗钉 | 遗迹封洞、符文守门者召唤 | 神器残片 + 符文石 + 遗迹核心 + 灵质 |
| 黑日残核 | 黑日核壳 | 灾变胎洞、黑日幼核召唤 | 神器残片 + 灾变晶核 + 灵质 + 符文石 |

专属材料不是直接生成神器。它只是让唤醒仪式更短、更便宜或更可定向。最终仍需要公开仪式，仍会暴露，仍可能被抢。

## 10. 洞穴与 PVP

洞穴不能变成安全刷本。PVP 交叉点包括：

- 入口脚印、矿车痕迹和灵压线索。
- 高价值房间开箱声。
- 召唤 Boss 的局部公告。
- Boss 低血量的短程脉冲。
- 携带神器材料撤离时的光痕。
- 洞穴出口附近的伏击点。

但也不能让洞穴变成必死口袋：

- 关键洞穴至少有两个撤离路径，或一个主出口加一个延迟开启的逃生裂隙。
- Boss 房不能被玩家永久封门。
- 火种、神器、专属材料掉落时必须落在可达点。
- 自动脱困会先把高价值物留在合法地面点，再移动玩家。

## 12. Bevy 插件与系统

```rust
pub struct CaveRoguePlugin;

impl Plugin for CaveRoguePlugin {
    fn build(&self, app: &mut App) {
        app.add_message::<CaveEnteredMsg>()
            .add_message::<CaveRoomRevealedMsg>()
            .add_message::<BossSummonStartedMsg>()
            .add_message::<BossSummonResolvedMsg>()
            .add_message::<ArtifactMaterialGrantedMsg>()
            .add_systems(FixedUpdate, (
                spawn_caves_from_worldgen.in_set(SimSet::Startup),
                reveal_cave_rooms.in_set(SimSet::Interaction),
                resolve_cave_triggers.in_set(SimSet::Interaction),
                start_boss_summon.in_set(SimSet::Interaction),
                tick_boss_summon_sites.in_set(SimSet::NationAndArtifact),
                resolve_boss_rewards.in_set(SimSet::ResourceAndLoot),
                update_artifact_awaken_progress.in_set(SimSet::NationAndArtifact),
            ));
    }
}
```

系统边界：

| 系统 | 职责 |
| --- | --- |
| `spawn_caves_from_worldgen` | 根据 seed 和路线生成洞穴入口与房间链 |
| `reveal_cave_rooms` | 玩家进入或侦测时逐步揭示房间 |
| `resolve_cave_triggers` | 处理奇遇、陷阱、开箱、矿心过载 |
| `start_boss_summon` | 校验祭坛、材料、PVP 阶段和读条 |
| `tick_boss_summon_sites` | 推进召唤读条、广播提示、处理打断 |
| `resolve_boss_rewards` | Boss 死亡后生成材料和审计 |
| `update_artifact_awaken_progress` | 根据材料推进神器唤醒 |

## 13. 网络同步

洞穴同步不发完整地下地图，只发必要状态：

| 数据 | 同步 |
| --- | --- |
| 洞穴入口 | 世界 seed + 已发现状态 |
| 已探索房间 | 房间 id、类型、连接、状态 |
| 召唤读条 | site id、progress、contesting player |
| Boss 状态 | Encounter snapshot |
| 神器材料掉落 | 掉落实体 + 强提示 |
| 洞穴危险 | event message + VFX |

客户端可以本地表现洞穴雾门、粉尘和房间装饰，但 Boss 生成、材料掉落、神器唤醒进度必须服务端权威。

## 14. UI/UX

洞穴 UI 要回答：

- 这个洞穴是什么类型？
- 已探索到哪个房间？
- 当前奖励是量材料还是珍稀材料？
- 召唤 Boss 需要什么材料？
- 召唤会暴露给谁？
- 打完后怎么撤离？

神器材料 UI 要显示两条路线：

- 量路线进度。
- 珍稀材料路线进度。

玩家必须清楚：拿到专属材料不等于已经安全拥有神器。它还要被带回祭坛或王座阵眼，并完成公开唤醒仪式。

## 15. MVP 范围

首发只做：

- 3 类洞穴：矿脉洞穴、遗迹封洞、旧王墓穴。
- 每个洞穴 3-5 个房间。
- 2 个奇遇式 Boss。
- 2 个召唤式 Boss。
- 5 种专属神器材料。
- 神器量路线和珍稀路线二选一唤醒。
- 洞穴入口、房间、Boss、材料掉落的服务端审计。

暂缓：

- 大型地下城。
- 多层迷宫。
- 随机词条 Boss。
- 长期洞穴进度保存。
- 经营世界影响洞穴收益。

## 16. 验收标准

- 玩家能发现洞穴入口并进入短房间链。
- 洞穴中至少存在采矿、宝箱、机关、奇遇或祭坛之一。
- 奇遇式 Boss 能由探索触发。
- 召唤式 Boss 能由材料投入触发，并产生局部提示。
- Boss 能掉落神器残片或专属神器材料。
- 神器可通过量路线或珍稀材料路线推进唤醒。
- 高价值材料必须可掉落、可抢夺、可审计。
- 洞穴不能成为安全刷本或不可逃脱地下死局。

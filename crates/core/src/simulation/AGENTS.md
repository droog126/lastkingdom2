# 模拟

拥有确定性节拍契约和系统排序。

- 为服务器权威、离线权威、场景执行和测试提供单一步骤路径。
- 应用经过验证的输入，推进自然系统，发出事件，并检查不变量。
- 明确大气、水文、植物、动物和分解之间的顺序。
- 绝不在规则内部读取挂钟时间或非确定性全局随机性。
- 不要在此处放置 Bevy 窗口、渲染、网络传输或进程逻辑。

## 当前锚点

- `WorldInput.tick` 由调用方提供；核心负责一次推进，不负责替调用方修正重复或倒退 tick。
- `step_world` 先推进 `EcoCycle`，再生成快照和事件；服务器、离线客户端、场景和测试都应走这条路径。
- `NatureSnapshot::is_finite` 是跨边界的基本健康检查，失败时应在权威边界拒绝发布。

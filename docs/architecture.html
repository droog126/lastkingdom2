万国起源：最后一国 钻石版

一个 Bevy 0.19 体素游戏 demo,核心特征是闭环 AI 迭代——游戏自己跑、自己截图、AI 读结果并决定下一步改什么,人不在回路里。

01

Workspace 结构

`crates/*` 下的三个 crate,core 是唯一的共享逻辑层

core lk2-core

共享仿真数据 / 协议 / 规则。TDD 首选位置——反馈最快、最稳定。所有可序列化逻辑都在这里。

入口

无,被 client/server 引用

cargo test -p lk2-core
client lk2-client

运行
cargo run -p lk2-client -- --offline

03

闭环迭代 · 项目的核心工作流

观察 → 决策 → 行动 → 构建 → 再跑,AI 不间断推动项目演化

1
观察 · health.json 优先体积比 PNG 小 2000 倍,先读它;FAIL/PARTIAL 才看 assertions
2
决策 · decision.md评分 6 维度(天空/玩家/地形/装饰/HUD/玩法),写明 next
3
行动 · 改代码纯逻辑走 TDD 先写测试,视觉改动最小化、聚焦 1–3 个相关问题
4
验证 · loop.ps1build + 12s run + 截图 + state 导出;无 decision.md = 没复盘

# 万国余烬：王冠赛季 地形高度与地表加料技术方案

**版本**：V2.0 重构设计版

**适用范围**：地图高度生成、chunk 切分、地表材质混合、植被/石块/资源撒点、道路/河流压印、碰撞/导航/小地图一致性

**最后更新**：2026-06-17

**文档定位**：本文件回答“地图高度怎么做、地表怎么加料”。它是《地形系统技术方案》和《程序化美术技术方案》的基础地形专项。

---

## 1. 核心结论

地形不要一开始做无限世界，也不要直接做全体素。MVP 推荐：

> 固定尺寸中型地图 + 高度场 Base Terrain + chunk mesh + 材质 mask + 程序化撒点 + 覆盖层改造。
> 

也就是说：

- Base Terrain 用高度图/高度场生成。
- 地表“加料”用材质 mask、生态 mask、资源撒点和装饰实例。
- 玩家改造不直接改 Base Terrain，而加 Edit Overlay。
- 水、道路、护城河、墙、坑、桥都压在覆盖层上。
- 服务器持有权威地形数据，客户端生成 mesh 和表现。

---

## 2. 地图尺寸建议

MVP 先用中型地图，别做无缝无限。

| 项目 | 推荐 |
| --- | --- |
| 地图尺寸 | 2048m x 2048m |
| chunk 尺寸 | 32m 或 64m |
| 高度采样间距 | 1m 或 2m |
| 地形 mesh LOD | 近 1m，中 2m，远 4m |
| 主要 POI 数量 | 12-18 |
| 主路线数量 | 3-5 |
| 水源数量 | 4-8 |

60 人局不需要过大地图。过大地图会让 PVP 稀释、运输太累、事件热度不足。

## 4. 生成流水线

```
Match Seed
  -> Macro Layout
  -> Height Field
  -> Slope / Moisture
  -> Biome Field
  -> Route Graph
  -> Roads / Rivers
  -> Material Masks
  -> POI Placement
  -> Resource Placement
  -> Mining Site Module Placement
  -> Cave Entrance Placement
  -> Decoration Scatter
  -> Collision / Nav / Minimap
```

顺序很重要：先有大地形和路线，再放资源和装饰。不要先撒树再找路。

---

## 5. Macro Layout

宏观布局决定这一局的节奏。

输入：

- 对局人数。
- 地图尺寸。
- 主路线数量。
- 王座区域。
- 出生区。
- 高风险区。
- 水源/山脊/湿地。

输出：

- 高地带。
- 低洼带。
- 主通道。
- 中央争夺区。
- POI 候选区。
- 水系候选区。

规则：

- 出生区不能直接贴高价值资源。
- 中央区域有 2-3 条可达路线。
- 王座区域至少两条进攻路线。
- 水系不能把地图天然切成不可通行两半。

---

## 6. Height Field

高度生成不要纯噪声，否则地图会难玩。推荐多层组合：

```
height =
  base_continent
  + hills_noise
  + ridge_field
  - river_valley
  - road_flatten
  + poi_flatten
  + local_detail
```

| 层 | 作用 |
| --- | --- |
| `base_continent` | 大范围起伏 |
| `hills_noise` | 丘陵和缓坡 |
| `ridge_field` | 山脊和矿区 |
| `river_valley` | 河谷压低 |
| `road_flatten` | 道路压平 |
| `poi_flatten` | POI 平台 |
| `local_detail` | 小起伏，不影响大路线 |

关键限制：

- 玩家常走区域坡度不要过高。
- POI 周边需要可战斗平面。
- Boss 场地不能有太多随机凸起。
- 主路要连续可走。

---

## 7. 坡度与可行走性

高度图生成后，必须计算 slope field。

| 坡度 | 玩法 |
| --- | --- |
| 0-15 度 | 好走，可建造大多数覆盖层 |
| 15-30 度 | 可走，速度略受影响 |
| 30-42 度 | 可走但慢，不适合推车 |
| 42-55 度 | 不能普通行走，需要攀爬/绕路 |
| 55 度以上 | 视为 cliff，不放普通资源点 |

坡度影响：

- 移动速度。
- 疾跑蓄势。
- 推车路线。
- 建筑放置。
- 资源节点可采集点。
- AI 导航。

---

## 8. Biome Field

Biome 不只是颜色，它决定资源和玩法密度。

| Biome | 高度倾向 | 湿度 | 主要资源 | 玩法 |
| --- | --- | --- | --- | --- |
| 王冠草原 | 中低 | 中 | 木、食物、纤维 | 开局、结盟、运输 |
| 月纹山脊 | 高 | 低 | 铁、银、月纹钢 | 矿权、秘剑 |
| 灵脉湿地 | 低 | 高 | 水、灵质、符文石 | 法术、护城河 |
| 星砂荒丘 | 中 | 低 | 星砂、遗迹核心 | 夜陨、遗迹 |
| 黑金王座 | 中高 | 低 | 火种、神器、王座碎片 | 终局 |

Biome 生成要平滑过渡，但资源点必须清晰，不要让玩家迷路。

## 9. 材质 Mask

地表材质不要一个 mesh 一个材质硬切。用 mask 混合：

- grass。
- dirt。
- rock。
- mud。
- shallow_water_edge。
- road。
- ruin_stone。
- spirit_vein。
- calamity_crack。

```rust
pub struct TerrainMaterialSample {
    pub grass: f32,
    pub dirt: f32,
    pub rock: f32,
    pub mud: f32,
    pub road: f32,
    pub ruin: f32,
    pub magic: f32,
}
```

规则：

- mask 权重总和归一。
- 道路和 POI 平台优先级高。
- 灵脉/灾变是叠加层，不要覆盖全部地貌。
- slope 高的地方 rock 权重上升。
- moisture 高的低地 mud 权重上升。

## 10. 道路压印

道路是玩法路径，不只是贴图。

道路生成：

1. 从出生区连到低风险 POI。
2. 从低风险 POI 连到中风险 POI。
3. 中央区域留 2-3 条分叉。
4. 终局王座区域至少两条主路。

道路会：

- 压平高度。
- 降低坡度。
- 调高 road mask。
- 清理过密装饰。
- 提高推车可通行性。
- 进入小地图图层。

---

## 11. 河流与低洼

河流和护城河的基础来自低洼高度。

河流生成：

- 先生成河流曲线。
- 沿曲线压低高度。
- 生成 river valley。
- 生成水源锚点。
- 设置浅水/深水边界。

规则：

- 河流不能切断所有主路。
- 每条河至少有天然浅滩或桥位。
- 玩家挖沟引水必须连接已有水源或水渠。
- 河边湿度高，适合草药、灵质和泥地。

---

## 12. POI 平台

POI 不能直接放在随机斜坡上。需要平台处理。

流程：

```
Select POI candidate
  -> sample local slope
  -> flatten platform
  -> create entrance ramps
  -> preserve route graph
  -> paint ruin/road material mask
  -> place POI modules
```

平台规则：

- 小 POI 平台 20-40m。
- 大 POI 平台 60-100m。
- Boss 场地必须有足够战斗空间。
- 平台边缘用坡道过渡，不要硬切。

---

## 13. 资源撒点与矿坑模块

资源撒点不是完全随机，而是 mask + 间距 + 风险规则。矿物资源要分成两种：低产地表露头和高产矿坑模块。

```
Candidate points
  -> biome weight
  -> slope filter
  -> distance to road
  -> distance to POI
  -> risk tier
  -> spacing check
  -> spawn ResourceNode or MiningSiteModule
```

| 资源/模块 | 撒点条件 |
| --- | --- |
| 木材 | 草原/森林，中低坡度 |
| 石料 | 岩地和坡面 |
| 铁/铜/银地表露头 | 山脊和岩地边缘，低产，作为早期提示 |
| 露天矿坑模块 | 山脊台地、旧矿路附近，需要可战斗平台 |
| 裂隙洞穴模块 | 山脊断层、岩壁脚下，必须有至少两个可达出口或逃生锚点 |
| 灵质 | 湿地、灵脉线、井附近 |
| 灵脉矿井模块 | 湿地边缘、灵脉交汇，带灵压脉冲 |
| 符文石 | 遗迹、洞穴模块、灵脉交汇 |
| 星砂 | 荒丘、夜陨区域 |
| 月纹矿坑模块 | 高地、月纹山脊，夜间高产 |
| 洞穴入口模块 | 山脚、遗迹边、矿坑深处、旧王路线旁，需可撤离路径 |

安全资源靠近出生和道路，高价值资源靠近风险区和 POI。真正高产的金属、符文和月纹钢不应只作为普通 `ResourceNode` 散在地图上，而应生成 `MiningSiteModule`，让玩家围绕入口、采矿槽、运输路线和防线做决策。

矿坑模块放置额外校验：

- 入口到主路可达。
- 周边有推车或肩扛搬运路线。
- 采矿槽不贴出生保护区。
- 不封死王座、Boss、遗迹主路径。
- 洞穴和深坑必须生成 `EscapeAnchor`。
- 高产矿坑在小地图上只给模糊矿区，不给精确槽位。
- 洞穴入口可隐藏或事件显影，但一旦显影必须有可达路径和撤离空间。

## 14. 装饰加料

“加料”分三种，不要混在一起：

| 类型 | 是否影响玩法 | 示例 |
| --- | --- | --- |
| 玩法实体 | 是 | 树、石料露头、采矿槽、宝箱、桥、墙 |
| 软阻挡装饰 | 轻微影响 | 小灌木、碎石、低栅栏 |
| 纯装饰 | 否 | 草簇、花、叶子、碎瓦 |

生成规则：

- 玩法实体必须服务端知道。
- 纯装饰可以客户端按 seed 生成。
- 软阻挡装饰必须不影响关键路径。
- PVP 区域不要放过多遮挡视线的小物。

## 15. 草、石、树实例

实例化撒点：

```
For each chunk:
  read biome/material/slope/moisture
  sample density map
  reject near road/POI/combat arena
  pick variant
  spawn render instance
```

密度建议：

| 区域 | 草 | 小石 | 树 |
| --- | --- | --- | --- |
| 草原 | 高 | 低 | 中 |
| 山脊 | 低 | 高 | 低 |
| 湿地 | 中 | 低 | 中 |
| 遗迹 | 低 | 中 | 低 |
| 王座 | 低 | 中 | 极低 |

低配只降纯装饰，不降资源节点和关键目标。

## 16. Chunk Mesh 生成

每个 chunk 生成：

- 顶点位置。
- 法线。
- UV。
- 材质 mask。
- collision heightfield。
- minimap sample。

推荐异步生成：

```
Generate TerrainMapData
  -> queue chunk build jobs
  -> build mesh data off main thread
  -> upload Mesh on main thread
  -> build collider
  -> register nav region
```

MVP 可以先同步生成小地图，后续改异步。

## 17. 碰撞和导航

Base Terrain 碰撞来自 heightfield。覆盖层有独立碰撞。

| 内容 | 碰撞 |
| --- | --- |
| Base Terrain | heightfield collider |
| 树/石料露头 | 简化 collider |
| 矿坑模块 | 入口碰撞 + 采矿槽交互体 + 内部简化碰撞 |
| 洞穴入口 | 入口触发体 + 房间链锚点，不生成完整自由地下碰撞 |
| 石墙/木墙 | box collider |
| 桥 | box/mesh collider |
| 浅沟 | PitVolume + 简化高度修正 |
| 水体 | WaterCell zone，不是实体碰撞 |
| 道路 | speed zone |

导航：

- Base Terrain 生成基础 nav。
- 道路降低移动成本。
- 水、泥、坡度提高移动成本。
- 墙、深沟、深水是阻挡或高成本区域。
- 覆盖层用增量 nav overlay。

## 18. 小地图生成

小地图来自同一份 TerrainMapData，不能手画另一套。

图层：

- 高度阴影。
- biome 底色。
- 道路。
- 水体。
- POI。
- 资源筛选。
- 地形覆盖层。
- 危险区。

生成方式：

```
TerrainMapData
  -> minimap raster
  -> overlay icons
  -> dynamic layers
```

动态层：火种、神器、地形改造、水体变化、国家补给圈。

## 21. 开发顺序

1. 先做固定平地 chunk。
2. 加高度场。
3. 加坡度计算和移动影响。
4. 加材质 mask。
5. 加道路压印。
6. 加低产资源撒点。
7. 加矿坑模块放置。
8. 加洞穴入口放置。
9. 加 POI 平台。
10. 加河流和水源。
11. 加装饰实例。
12. 加小地图 raster。
13. 接入地形覆盖层。
14. 接入水体和护城河。

## 22. 验收标准

- 同一 seed 生成同一张地形。
- 地图有高低起伏，但主路线可走。
- 道路明显降低坡度并进入小地图。
- POI 周边有可战斗平台。
- 资源分布符合 biome 和风险层级。
- 高产矿物来自矿坑模块，地表露头只做低产过渡和路线提示。
- 草石树装饰不会遮挡关键路径和 PVP 读招。
- Base Terrain、碰撞、导航、小地图使用同一份数据源。
- 玩家改造仍通过覆盖层实现，不直接破坏 Base Terrain。

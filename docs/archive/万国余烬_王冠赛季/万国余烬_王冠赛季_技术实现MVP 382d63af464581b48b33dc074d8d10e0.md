## 1. MVP 目标

实现一个可玩的双层闭环：

1. 玩家进入匿名赛或公开活动赛。
2. 单局生成随机地形、资源、事件和路线。
3. 开局保护期后进入资源争夺和 PVP。
4. 玩家争夺王权火种并建立国家。
5. 中后期通过局内秘剑谱、法术环和王权秘仪进入高阶奇幻战争。
6. 终局全图 PVP，产生单局胜者。
7. 公开活动赛结算排名，更新王冠经营世界治理权。
8. 玩家进入经营世界进行社交、家具、皮肤和活动运营。

Bevy 0.18 的插件拆分、组件/资源、SystemSet、Message、固定帧模拟和项目目录见《Bevy 0.18 架构实现》。渲染、插值同步、人物、UI 和地形的专项落地分别见《渲染技术方案》《插值与预测同步系统》《人物设计与角色技术方案》《UI设计技术方案》《地形系统技术方案》。本文只保留工程范围和验收。

## 2. 服务端模块

| 模块 | 职责 | MVP 验收 |
| --- | --- | --- |
| MatchService | 匿名赛、公开活动赛、阶段时间、结算 | 能完整跑完一局 |
| ProtectionService | 开局保护、中途加入保护、事件保护规则 | 保护期不能攻击也不能被攻击 |
| WorldGenService | 随机地形、资源点、遗迹、Boss、事件点 | 同 seed 可复现，路线可变化 |
| POIService | 背景建筑、入口、可破坏层、关键路径 | POI 能承载探索、宝箱和遭遇，不能被完全封死 |
| LootContainerService | 宝箱、容器、开箱条件、掉落表、陷阱 | 宝箱可开启、可打断、可触发风险 |
| EncounterService | 怪物、小怪、精英、Boss、巡逻和仇恨 | 怪物能守资源、守宝箱和参与事件 |
| ResourcePoolService | 资源池、消耗、掉落、回流、审计 | 关键资源不凭空生成 |
| MiningSiteService | 矿坑模块、采矿槽、爆率、枯竭、采矿暴露 | 高产矿物来自可争夺矿坑而非自由挖洞 |
| CaveRogueService | 肉鸽洞穴、房间链、奇遇、召唤 Boss、神器材料 | 洞穴能产出量材料或珍稀材料，但不能成为安全刷本 |
| EquipmentService | 装备槽、品质、耐久、维修、掉落 | 装备能穿戴、损耗、掉落和维修 |
| StatService | 属性聚合、上限、伤害公式、负重公式 | 数值能配置、可审计且不无限叠加 |
| TerrainEditService | 挖掘、建造、爆破、预算、禁区 | 能改造但不能无限封锁 |
| SovereignSparkService | 王权火种生成、持有、掉落、交易、建国、回流 | 火种能驱动建国与争夺 |
| NationService | 临时国家、成员、据点、任务、淘汰 | 单局国家可建立和灭亡 |
| CombatService | 身法、剑术、招架、法术、结界、伤害结算 | 前中后期战斗流派可用 |
| ArcanaRouteService | 秘剑谱、法术环、遗迹解锁、王权秘仪 | 秘仪路线只在单局内有效 |
| UniqueArtifactService | 全局唯一神器生成、公告、持有、激活、反制、掉落、封印 | 神器能改写战局但不能带出单局 |
| EventService | 肉鸽事件、局部 PVP、全局 PVP、终局收束 | 事件能改变战局 |
| RankingService | 公开活动赛积分、排名、治理权替换 | 排名能更新治理权 |
| CrownWorldService | 经营世界、公共区、家具、皮肤、活动 | 经营不提供战斗数值 |

## 4. 配置化要求

必须配置：

- 对局人数和时长。
- 开局保护时长。
- 中途加入保护时长。
- PVP 事件类型。
- 宝箱刷新数量、掉落表、开启条件和陷阱概率。
- 背景 POI 类型、入口规则、可破坏层和关键路径保护。
- 怪物和 Boss 的刷新、仇恨、掉落和事件绑定。
- 矿坑模块数量、品级、槽位、爆率、枯竭、强采风险、噪声和灵压半径。
- 洞穴模块数量、房间链长度、奇遇触发、召唤 Boss 材料、神器材料掉落和撤离暴露。
- 装备槽位、品质、耐久、维修、死亡掉落。
- 核心属性、伤害公式、减伤公式、负重公式和数值上限。
- 王权火种生成数量和回流比例。
- 资源池上限。
- 地形改造预算。
- 身法、剑术、招架、施法和法阵参数。
- 局内秘剑谱、法术环和秘仪路线。
- 全局唯一神器生成、持有、激活、反制、掉落、封印和重新广播规则。
- 公开活动赛积分规则。
- 王冠经营世界治理周期。
- 渲染 LOD、VFX 数量、描边优先级和低配降级。
- 人物装备挂点、动画状态标签和皮肤可读性限制。
- UI 图标、颜色、提示优先级和高风险确认文案。

## 4.1 Bevy 0.18 架构约束

- 玩法系统必须拆为 Bevy Plugin，不允许长期堆在单个 `main.rs`。
- 权威模拟放在 `FixedUpdate`，表现、镜头、UI 和 VFX 放在 `Update` / `PostUpdate`。
- 跨系统玩法通信优先使用 `Message` / `MessageReader` / `MessageWriter`。
- 客户端 State 可用 Bevy `States`；专服多房间不能用全局 App State 表示每场对局阶段。
- 表格包数值必须通过配置加载进入 `GameTables`，系统不得硬编码核心数值。
- 装备、数值、神器、资源池和公开赛计分必须有服务端权威校验。
- 渲染、人物动画和 UI 系统只能消费 Snapshot / PresentationState，不能直接写权威玩法组件。
- 地形改造必须使用服务端确认的覆盖层实体，客户端预览不参与权威碰撞。

## 5. 验收标准

### 5.1 单局

- 开局 5 分钟保护期生效。
- 中途加入 5 分钟保护生效。
- 肉鸽事件能打开局部或全局 PVP。
- 背景 POI 能生成宝箱、资源、怪物和路线线索。
- 宝箱能按条件开启、掉落资源，并在高价值时触发声音或提示。
- 怪物能守资源、守宝箱、掉落局内资源，且不产出长期战力。
- 高产矿物来自矿坑模块；采矿会占用槽位、扣除资源池、产生暴露并进入负重运输。
- 肉鸽洞穴能生成短房间链，奇遇式 Boss 和召唤式 Boss 能产出神器残片或专属神器材料。
- 装备能穿戴、损耗、维修、掉落，并影响负重和动作。
- 数值系统能正确聚合装备、状态、负重、法术和神器效果，并显示上限。
- 王权火种能生成、掉落、交易、建国和回流。
- 玩家能从基础身法进阶到秘剑、法术和王权秘仪。
- 全局唯一神器能生成、公告、持有、激活、被反制、掉落、封印或参与仪式。
- 地形可有限改造，关键目标不能被永久封死。
- 单局能产生胜者。

### 5.2 公开活动赛

- 公开活动赛结算排名。
- 排名能替换王冠世界治理权。
- 治理权替换不删除个人资产。

### 5.3 经营世界

- 玩家能进入经营世界。
- 治理者能编辑公共区域和发布活动。
- 玩家能获得家具、皮肤、社交经验。
- 经营资产不能影响下一场对战的伤害、血量、装备、资源、复活、秘剑谱、法术环和秘仪研究。

MVP 暂缓：

- 复杂外交条约。
- 经营世界商业化深水系统。
- 玩家创作内容审核后台。
- 大型观战导播系统。
- 跨赛季剧情战役。
- 长期战力养成。

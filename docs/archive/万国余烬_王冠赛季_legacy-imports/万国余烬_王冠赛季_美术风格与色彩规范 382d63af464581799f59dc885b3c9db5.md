## 1. 整体美术方向

《万国余烬：王冠赛季》的视觉关键词是 **余烬王权、星月灵脉、优雅剑术、奇幻法术、荒野建国**。

整体不能做成脏乱的写实战争，也不能做成满屏霓虹的科幻感。世界应当有手工材质、古代遗迹、自然荒野和仪式感；战斗表现应当轻盈、清晰、有舞蹈感，剑术靠轨迹、姿态和节奏表达，法术靠法阵、符文、结界和灵脉流动表达。

画面基调建议为 **低饱和自然地貌 + 高价值资源局部发光 + 王权目标强轮廓**。玩家平时看见的是可信的荒野和遗迹；一旦出现王权火种、全局唯一神器、灵脉污染、阵眼和终局王座，画面才进入更强的魔幻亮度。

---

## 2. 色彩原则

1. **地形低饱和，资源高识别**：草、岩、泥、水不能抢戏。资源节点、火种、神器、阵眼必须能一眼识别。
2. **玩法颜色优先于皮肤颜色**：皮肤不能伪装成资源、敌我标识、神器辉光或危险区域。
3. **发光只给交互和魔法**：普通木头、石头、道路不发光。灵质、符文、星砂、王权火种、神器、法阵和结界可以发光。
4. **不要单色统治世界**：禁止整张地图长期被紫、蓝、灰、沙黄或橙红单色覆盖。每个区域必须有材质主色、资源点缀色和危险提示色的层级。
5. **PVP 可读性优先**：敌我、危险、神器持有者、火种持有者、阵眼进度的 UI 色优先级高于环境美术。

## 8. 经营世界与皮肤颜色限制

经营世界可以更亮、更温柔、更社交，但进入对战后必须降噪。

允许：

- 家具主题使用更丰富的布料色、陶器色、玻璃色和花色。
- 角色皮肤拥有不同服装主色。
- 剑饰和法术色彩可做外观变体。
- 王冠经营者公共区可以使用王冠金、余烬橙和月银做身份展示。

禁止：

- 皮肤伪装成草地、岩石、木箱、灵脉、王权火种或神器。
- 法术皮肤改变敌我判读。
- 使用敌意红作为普通可爱装饰大面积主色。

洞穴是短链路肉鸽模块，视觉上要像“危险路线”，不是安全副本大厅。每类洞穴必须让玩家在入口处就能判断大致路线。

Boss 场地必须满足三条可读性规则：

- **边界可读**：场地边缘、出口、逃生裂隙不能被暗色吞掉。
- **读招可读**：Boss 前摇、法阵、剑影和污染边界优先级高于背景发光。
- **PVP 可读**：敌方进入洞穴或Boss场时，敌我标识优先于场景粒子。

召唤式 Boss 的祭坛视觉必须和普通宝箱区分。祭坛使用圆环、刻度、材料槽和向外扩散的灵压线；读条期间的光效从中心向入口方向泄出，暗示“外面的人能看见了”。

## 15. 背景层级与镜头阅读

同一屏幕内应保持三个层级：

- **背景层**：地貌、建筑主体、不可交互远景，低饱和、低对比。
- **交互层**：宝箱、采集节点、可破坏结构、怪物弱点，中等对比，有轮廓。
- **战略层**：王权火种、全局唯一神器、阵眼、敌方、危险区，高对比、强形状、节奏闪烁。

如果背景建筑太亮，应降低材质饱和度，把亮度留给入口、宝箱、机关槽和危险提示。玩家必须能在 1 秒内判断哪里能进、哪里能开、哪里危险、哪里是王权目标。

## 16. 落地检查清单

- 资源图标、掉落物、采集节点、小地图图标是否使用同一识别色。
- 地形主色是否足够低饱和，不抢资源和敌我标识。
- 王权火种和全局唯一神器是否在远距离、低画质和色弱模式下仍可识别。
- 皮肤是否没有占用敌方红、火种橙白内核、神器黑金轮廓。
- 洞穴、矿坑、夜间区域是否保留足够导航边缘。
- 背景建筑入口、宝箱位置、怪物前摇是否在低画质下仍可读。
- 法术特效是否能看出来源、范围、敌我和剩余时间。
- 高价值携带物是否有辉光、拖痕、脉冲或小地图模糊提示。
- 同屏多个事件发生时，敌方、危险区域、王权火种、神器的优先级是否高于普通资源。
- 洞穴入口是否能从远处看出类型，近处看出出口、宝箱、祭坛和危险。
- 召唤 Boss 的读条光效是否能让玩家理解“这会暴露”。
- 珍稀神器材料是否不被误认为普通装备、普通骨头或普通金币。

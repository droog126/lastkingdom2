# 生态系统

负责植物、动物、分解、种群、栖息地和食物网相互作用。

- 植物和动物是权威的有机体，绝不是定时的视觉生成。
- 出生、生长、进食、繁殖、迁徙、死亡和分解需要可解释的原因。
- 通过可审计的变化转移生物量、水、营养物质和能量。
- 整合旧的 `creature`、`monster` 和生态代码中的兼容行为，而不是复制。
- 将动画、模型、粒子和面向相机的行为保持在客户端。

## 当前锚点

- `EcoCycle::tick` 仍是云雨、植物、浆果、兔子和大型野生动物的实际规则来源，并返回可审计的 `EcoTickReport`。
- `NatureEcologySnapshot` 和 `EcoSnapshot` 是观察/复制边界；不要把摘要字段当作可独立写入的权威状态。
- 生态目录同时关联可收集内容与模型路径，新增种类要保持枚举、目录和资源产出一致。

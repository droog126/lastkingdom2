- 数值冲突时，以《表格包》为准。

- 玩法规则冲突时，以《对战设计案》《经营世界设计案》《资源循环与地形改造》为准。
- Bevy 实现冲突时，以《Bevy0.18架构实现》为准。
- 工程范围冲突时，以《技术实现MVP》和《开发顺序与里程碑》为准。

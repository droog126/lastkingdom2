## 核心设计原则

### 1. 世界自运行
服务端启动后，世界按照物理法则和生态规则**自行演化**，无需客户端连接。
- 植物生长、动物繁殖、天气变化持续进行
- 国家 AI 自动管理（如果没有玩家国王）
- 经济系统自我调节

### 2. 资源守恒
世界总质量/能量为**常量**，任何变化都是形态转化。
- 没有"刷新"，只有"转化"
- 所有资源变动可追溯、可审计
- 玩家行为受物理法则约束

### 3. 涌现式玩法
设计者只定义**底层规则**，玩法由规则自发涌现。
- 过度放牧 → 草原退化 → 沙尘暴
- 筑坝截流 → 上游洪水 / 下游干旱
- 文明崛起 → 新技术涌现

### 4. 确定性模拟
给定相同的初始种子 + 输入序列，任何时刻的世界状态都可以**精确复现**。
- 支持时间倒带（查看历史）
- 支持平行分支（实验不同选择）
- 支持跨平台一致性验证

### 5. 多时间流速
不同区域/维度可以有不同的时间流速。
- 农场 10x 加速，主城 1x 正常
- 以太界 0.5x + 重力扭曲
- 分支时间线独立演化

## 快速开始

### 开发环境搭建

```powershell
# 1. 安装 Rust (需要 1.85+)
# 参考 https://www.rust-lang.org/tools/install

# 2. 进入项目目录
cd F:\rustProject\lastkingdom2

# 3. 构建
just build

# 4. 启动服务端
cargo run -p lk2-server

# 5. 启动客户端（在线模式）
cargo run -p lk2-client -- --connect=127.0.0.1:5000

# 5. 启动客户端（离线模式，推荐开发用）
cargo run -p lk2-client -- --offline

# 6. 闭环迭代
just loop
```

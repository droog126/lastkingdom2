## 3. 状态机

### 3.1 MatchPhase

```
OpeningProtection -> WildRace -> SovereignRise -> Endgame -> Finished
```

### 3.2 PVPRuleState

```
NoPvP -> NormalPvP -> EventLocalPvP -> GlobalPvP
```

开局保护期为 NoPvP。事件可开启 EventLocalPvP。终局收束进入 GlobalPvP。

### 3.3 SovereignSparkState

```
Dormant -> Spawned -> Carried -> BoundToNation -> Recycled
Spawned -> Dropped -> Carried
BoundToNation -> ConsumedByVictory
```

### 3.4 CrownGovernanceState

```
Unassigned -> Assigned -> Replaced -> Archived
```

治理权替换只影响公共治理权限，不删除个人 SocialAsset。

### 3.5 LootContainerState

```
Locked -> Opening -> Opened
Locked -> Broken
Opening -> Interrupted -> Locked
Opening -> Trapped -> Locked
```

高价值容器进入 Opening 时可以触发声音、守卫或局部提示。Opened 后不再刷新同一份奖励，Broken 只掉落低比例材料。

### 3.6 EncounterState

```
Idle -> Patrol -> Aggro -> Casting -> Aggro
Aggro -> Leashing -> Patrol
Aggro -> Defeated
```

怪物不追出事件边界太远。Boss 可在阶段切换时进入 Casting 或召唤守卫。

### 3.6.1 MiningSiteState

```
Dormant -> Active -> Contested -> Active
Active -> Hazard -> Active
Active -> Depleted
Hazard -> Collapsed -> Depleted
```

矿坑是高产资源模块，不是自由地形破坏。Depleted 后入口和地貌仍保留，但采矿槽产出降级或关闭。

### 3.6.2 CaveModuleState

```
Hidden -> Revealed -> Active -> Contested -> Active
Active -> Cleared
Active -> Collapsed
```

洞穴是短房间链，不保存长期进度。Cleared 后不刷新同一份高价值奖励，Collapsed 表示事件失败或危险收束。

### 3.6.3 BossSummonState

```
Dormant -> Charging -> Summoned -> Spent
Charging -> Interrupted -> Dormant
```

召唤读条期间会消耗或锁定材料，并产生局部提示。Interrupted 掉落部分材料，不能无成本反复试探。

### 3.7 EquipmentState

```
Stored -> Equipped -> Dropped
Equipped -> Broken -> Recycled
Stored -> Recycled
Dropped -> Equipped
```

装备死亡掉落后进入 Dropped。耐久归零进入 Broken，Broken 装备可携带但主要效果失效。

### 3.8 UniqueArtifactState

```
Dormant -> Manifested -> Carried -> Active -> Carried
Carried -> Dropped -> Carried
Carried -> Sealing -> Sealed
Sealing -> Dropped
Dropped -> Recalled -> Manifested
```

神器不进入普通装备槽。Sealing 可被打断；Dropped 超时无人拾取会 Recalled 并重新广播。

## 4. 关键伪逻辑

### 4.1 PVP 判定

```
function CanDamage(attacker, target, location):
    if attacker.id == target.id:
        return false
    if Now() < attacker.protection_until:
        return false
    if Now() < target.protection_until:
        return false

    match = GetMatch(attacker.match_id)
    if match.pvp_rule_state == NoPvP:
        return false
    if match.pvp_rule_state == GlobalPvP:
        return true
    if match.pvp_rule_state == EventLocalPvP:
        return IsInsideActivePvPEvent(location)
    return true
```

### 4.3 宝箱开启

```
function StartOpenContainer(player, container):
    if container.state != Locked:
        return Deny("ContainerNotReady")
    if !HasRequiredToolOrCondition(player, container):
        return Deny("RequirementMissing")
    if IsHighValue(container):
        Emit OnLootContainerOpenStarted(container.id, player.id, container.open_time)
        BroadcastNoise(container.location, container.risk_profile.noise_radius)
    container.state = Opening
    container.opener_player_id = player.id
    Schedule(container.open_time, CompleteOpenContainer, player.id, container.id)

function CompleteOpenContainer(player_id, container_id):
    player = GetPlayer(player_id)
    container = GetContainer(container_id)
    if container.state != Opening:
        return
    if !IsPlayerStillOpening(player, container):
        container.state = Locked
        Emit OnLootContainerInterrupted(container.id, player.id, "MovedOrDamaged")
        return
    loot = RollLoot(container.loot_table_id)
    ApplyResourceRewards(loot.resources)
    SpawnItemsAt(container.location, loot.items)
    container.state = Opened
    Emit OnLootContainerOpened(container.id, player.id, loot)
```

### 4.5 矿坑采矿

```
function StartMining(player, site, slot, mode):
    if site.state not in [Active, Contested]:
        return Fail("MiningSiteUnavailable")
    if slot.state != Ready:
        return Fail("SlotUnavailable")
    if !HasMiningTool(player, slot):
        return Fail("ToolMissing")
    if IsProtectedFromHighValueInteraction(player):
        return Fail("ProtectedPlayerCannotMineRichSlot")
    slot.occupied_player_ids.add(player.id)
    slot.state = Mining
    Emit OnMiningStarted(player.id, site.id, slot.id, mode)

function TickMiningSlot(site, slot):
    progress = CalcMiningProgress(slot, occupied_players, tools, weak_point_chain)
    instability = CalcInstability(slot, mode, site.depletion)
    slot.progress += progress
    slot.instability += instability
    if ShouldEmitNoise(slot):
        Emit OnMiningNoiseEmitted(site.id, CalcNoiseRadius(slot), CalcRevealType(slot))
    if slot.instability >= HazardThreshold(slot):
        TriggerMiningHazard(site, slot)
    if slot.progress >= RequiredProgress(slot):
        ResolveMiningYield(site, slot)

function ResolveMiningYield(site, slot):
    yield = RollMiningYield(site.grade, slot.yield_profile, site.resource_pool)
    yield = ClampByRemainingPool(yield, site.resource_pool)
    DeductFromResourcePool(site.resource_pool, yield)
    GrantResourcesToCargoOrInventory(slot.occupied_player_ids, yield)
    UpdateSiteDepletion(site)
    Emit OnMiningYieldGranted(primary_player(slot), site.id, slot.id, yield)
```

### 4.6 洞穴探索与 Boss 召唤

```
function EnterCave(player, cave):
    if cave.state == Hidden:
        cave.state = Revealed
    if !CanEnterCave(player, cave):
        return Fail("CannotEnterCave")
    cave.state = Active
    first_room = GetEntranceRoom(cave)
    RevealRoom(cave, first_room)
    Emit OnCaveEntered(cave.id, player.id)

function RevealRoom(cave, room):
    if room.state == Hidden:
        room.state = Revealed
        SpawnRoomContent(room)
        Emit OnCaveRoomRevealed(cave.id, room.id, room.room_type)

function ResolveCaveTrigger(player, room, trigger):
    if trigger.type == "EncounterBoss":
        boss = SpawnEncounter(trigger.boss_type, room.location)
        Emit OnCaveEncounterTriggered(room.cave_id, room.id, boss.id, "Encounter")
    if trigger.type == "ArtifactMaterialChest":
        StartOpenContainer(player, trigger.container)
```

```
function StartBossSummon(players, summon_site):
    if summon_site.state != Dormant:
        return Fail("SummonSiteUnavailable")
    if !AllPlayersCanInteract(players, summon_site):
        return Fail("InvalidSummoners")
    if !PayOrLockSummonCost(players, summon_site.required_cost):
        return Fail("CostMissing")
    summon_site.state = Charging
    summon_site.progress = 0
    summon_site.summoner_player_ids = players.ids
    BroadcastLocalReveal(summon_site.location, summon_site.reveal_level)
    Emit OnBossSummonStarted(summon_site.id, players.ids, summon_site.boss_type, summon_site.required_cost)

function TickBossSummon(summon_site):
    if summon_site.state != Charging:
        return
    if SummonersMovedOrDamaged(summon_site):
        dropped = DropPartialSummonCost(summon_site)
        summon_site.state = Interrupted
        Emit OnBossSummonInterrupted(summon_site.id, "MovedOrDamaged", dropped)
        return
    summon_site.progress += FixedDelta()
```

```
function RecalculateStats(player):
    stats = BaseStats(player)
    for equipment in GetEquippedItems(player):
        if equipment.state != Broken:
            stats = ApplyModifiers(stats, equipment.stat_modifiers)
    for status in GetActiveStatuses(player):
        stats = ApplyModifiers(stats, status.modifiers)
    for artifact in GetHeldArtifacts(player):
        stats = ApplyModifiers(stats, artifact.burden_modifiers)
    stats = ClampStats(stats, Config.StatCaps)
    snapshot = SaveStatSnapshot(player.id, stats)
    Emit OnStatsRecalculated(player.id, snapshot.source_hash, snapshot)
```

```
function ResolveDamage(attacker, target, hit):
    attacker_stats = GetStatSnapshot(attacker.id)
    target_stats = GetStatSnapshot(target.id)
    base = GetBaseDamage(hit.ability_id, hit.equipment_id)
    hit_mod = GetHitModifier(hit.angle, hit.momentum_state)
    resist = GetResistanceModifier(hit.damage_type, target_stats)
    guard = ResolveGuard(target, hit)
    final_damage = Ceil(Max(1, base * hit_mod * resist * guard + hit.flat_bonus))
    ApplyHPDelta(target, -final_damage)
    ApplyDurabilityLoss(hit.equipment_id, hit)
    ApplyDurabilityLoss(target.guard_equipment_id, hit)
```

- 每个神器材料从哪个 Boss、宝箱或奇遇产生，被谁搬运、掉落、消耗或抢夺。
- 每次地形改造是否经过预算和禁区校验。
- 经营资产是否被用于战斗数值。
- 公开活动赛排名如何替换治理权。
